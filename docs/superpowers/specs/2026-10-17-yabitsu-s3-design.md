## 1. 目的と、なぜこの形か

国道246号の名古木交差点から、蓑毛・菜の花台を通ってヤビツ峠まで、**途切れずにつながった1本の道**として走れるようにする。最終目標（246 → 宮ヶ瀬）のうち、秦野側の残り1区間。

- 重視することは S1・S2 と同じ：道の線形・高低差・道幅の正確さ
- そのうえで、**名古木交差点のまわり（半径 200m）は特に細かく作る**（ユーザーの指定）。ここはコースの「入口」で、毎回目に入る場所なので、地図どおりの道の形と、実物どおりの建物にする
- ユーザーは Blender・コース制作の初心者。手作業は渡さず、Claude が自動で作る。ユーザーは走って確かめ、Street View での地点確認を手伝う

## 4. 作るもの

### 4.1 S3 の道（S2 の下につなぐ）

S1・S2 と同じ手順で作る（OSM の中心線 → 空中写真で位置確認 → 地理院の標高で高さ → 道幅 → 地形 → 擁壁・ガードレール → 中央線・路面の模様）。

- `config.SECTIONS` の先頭に S3 を足す（並びは道の下から上：s3 → s2 → s1）。区間ごとの表は `data/manual/s3_*.csv` に新しく作り、S1・S2 の表は書き換えない
- 道の始まりは名古木交差点の中（交差点の中心）。S3 上りのスタート列は交差点のすぐ北の県道70号の上に並べる
- 道幅・擁壁・ガードレール・歩道・中央線：Claude が Street View を約50m ごとに見て決め、結果をユーザーに見せて OK をもらってから反映する（S2 と同じ）
- 町なかの区間では、歩道（縁石つき）、横断歩道、止まれの線、道路わきの家の塀・生け垣の「壁」も Street View で確かめて入れる
- 道ぞいの横道：ヤビツ方面以外へは進めないようにする（4.3）
- S2・S1 の道（位置・高さ・見た目・スタートなど）は変えない。蓑毛のつなぎ目から約30m より先は、今と 0.1m 以内にそろえる

### 4.2 名古木交差点のまわり（半径 200m）

ここだけは「1本の道」ではなく、**地図どおりの道のあみ目**として作る。

- **道の形**：交差点の中心から半径 200m 以内の道を、OSM の道の線と空中写真（地理院のシームレス写真）で位置を合わせて作る。車道は道幅、歩道・縁石、交差点の角の丸み、中央分離帯・右折レーンがあればそれも入れる
- **路面の表示**：停止線、横断歩道、車線の境の線、右折・直進の矢印、中央線。空中写真と Street View で場所と形を確かめる
- **信号機**：200m 以内の信号機（車用・歩行者用）を、実物の位置と向きで置く（点灯は固定。色が変わる仕組みは作らない）
- **建物**：4.4
- **高さ**：交差点のまわりは地理院の 5m 標高をもとに、道どうしが段差なくつながるように高さを合わせる
- **ガードレール・柵・電柱など**：Street View で目立つもの（ガードレール、歩道の柵、バス停の標識、駐在所の前の看板など）は置く。電線は張らない

### 4.3 ヤビツ方面以外の道の封鎖

- 交差点の 200m 以内にある、ヤビツ方面（県道70号）以外の道（国道246号の東西、県道704号、南の道、連絡路、住宅地の道）は、**見た目は地図どおりに作るが、車では入れない**ようにする
- 封鎖には「工事中の柵」を置く：黄色と黒（または赤と白）のしま模様のバリケード、カラーコーン、「工事中」の看板。柵の後ろに見えない壁を置き、車が抜けられないようにする
- 柵を置く位置：ヤビツ方面以外の道の入口（交差点のすぐ手前、横断歩道の外側）。一歩も入れない。国道246号の東西・県道704号・南の道・連絡路それぞれの入口に置く。交差点から見えない場所（200m 以内の住宅地の奥の道など）は、柵を置かずに見えない壁だけでよい
- 町の範囲の外の、本線（S1〜S3）の分かれ道：入口から 約40m（道がそれより短ければ道の終わりまで）を、地図の道の線どおりに作る。入口に工事中の柵＋見えない壁を置き、入れないようにする（ユーザーの指定）。ピットや広場に使う場所（菜の花台の駐車場、峠のわき道、蓑毛の折り返し場）の入口はふさがない

### 4.4 建物

| 範囲 | 細かさ |
|---|---|
| 交差点から半径 200m | **できる限り実物どおり**。形は地理院の建物の外周線と OSM の建物の形をそのまま使う（四角に丸めない）。階数・高さ・屋根の形（平らな屋根／三角屋根／片流れ）・壁と屋根の色・窓のならび・1階の店の入口のガラス・店の看板は、Street View で1棟ずつ確かめて決める。店の駐車場（舗装と白線）、ガソリンスタンドなどの屋根も入れる |
| それより先の S3 の道ぞい | 蓑毛と同じ細かさ（道から 約40m 以内の家を、外周線の形の箱＋屋根で。色は Street View で近いものに） |

- 店の看板：看板の位置・大きさ・色と店の名前の文字までにする。会社のロゴの絵は写さない（ユーザー確認済み）
- 建物の窓などは、壁の絵（テクスチャ）で表す。建物の中は作らない

## 6. 完成の条件（受け入れ基準）

S1・S2 の基準（道の位置が空中写真と約2m以内、高さが標高データと ±1.5m 以内、不自然な段差なし、完走・計測・壁すり抜けなし、カクつかない、見た目に違和感なし）を S3 にも当てはめ、さらに次を満たすこと。

| 観点 | 基準 |
|---|---|
| 交差点まわりの道 | 半径 200m の道の線が空中写真と約1m以内。道と道のつなぎ目に段差・すき間がない |
| 封鎖 | ヤビツ方面以外のどの道からも、柵の先へ出られない（壁のすり抜けなし）。AI 車が封鎖した道へ入らない |
| 建物 | 交差点 200m 以内の建物が、Street View と並べて見て、位置・形・高さ・色・看板が「同じ建物」と分かる |
| つなぎ目 | 蓑毛の境目で段差・折れなし |
| S1・S2 が変わっていない | 回帰テスト（つなぎ目 30m より先は 0.1m 以内）、既存の4レイアウトのスタート・ピット・計測位置が同じ場所 |
| レイアウト | 新しい4つと既存の4つのどれも、スタートからゴールまで走れてタイムが出る |
| 動作 | 道が 11.8km になり、町の建物が増えても、ユーザーの PC でカクつかない |

## 7. 想定されるリスクと対策

| リスク | 対策 |
|---|---|
| 今の作りは「1本の道を横断面で作る」形で、交差点の道のあみ目を作れない | 交差点まわり用に「道のあみ目」を作る部品を新しく作る（道ごとの帯＋交差点の面）。S3 の本線は今の作りのまま。最初に交差点だけの小さな試作を作り、ユーザーに走って見てもらってから広げる |
| 建物の確認の手間（200m 以内に数十棟） | Claude が Street View の画像を自動で集めて1棟ずつ決め、一覧表にしてユーザーに見せる。ユーザーは気になる建物だけ指摘する |
| ゲーム用ファイルが重くなる（今 95MB／7.5km） | kn5 を区間ごとに分ける。建物は形を簡単にし、壁の絵を共用する。FPS をユーザーに確かめてもらう |
| 町なかで地形と建物・道がずれる（標高データに建物や塀の影響） | 道と建物の足元の高さを、まわりの道の高さにそろえる（`site.fit_plane` と同じ考え方） |
| 交差点の Street View が新しい／古い時期で違う | 一番新しい撮影日の画像を使い、表に撮影年月を書く |

## 8. Claude の判断で決めたこと

- 新しいレイアウトとして「全線 上り／下り」（名古木 ⇄ 峠）も足す
- 信号機は置くが、灯火は固定（色は変わらない）
- 交差点の試作を先に作り、ユーザーの確認を受けてから S3 全体を作る
- 信号の灯火は、車用は青、歩行者用は赤が点いた絵で固定する
- 交差点まわりで車が走れるのは、県道70号と交差点の中（と、そのまわりの歩道）だけ。その外側（店の駐車場や敷地）との境には見えない壁を置く。ピットに駐車場を使うときは、その駐車場だけ走れる範囲に入れる
- 屋根の色は、まず空中写真の色から自動で決め、交差点 200m 以内は Street View で確かめて直す

## 9. Claude に任せること

- プログラムの組み立て方（道のあみ目の作り方、ファイルの分け方など）。ただし 4.1 の決まりは守る
- 道幅・擁壁・歩道などの細かい値、建物の細かい形と色
- スタート・ピット・計測位置の最初の案（最終決定はユーザー）
