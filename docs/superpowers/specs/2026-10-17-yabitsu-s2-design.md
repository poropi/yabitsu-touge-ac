# ヤビツ峠 再現コース 設計書（S2：蓑毛 → 菜の花台、S1 とつなげる）

- 作成日：2026-10-17
- 前提：S1（菜の花台 → ヤビツ峠）は完成済み（`docs/s1-acceptance.md`、ブランチ `feat/s1-pilot`）。全体構成・座標系・作り方は `2026-10-17-yabitsu-s1-design.md` を引き継ぐ
- 状態：レビュー待ち

## 1. 目的と、なぜこの形か

蓑毛のバス停から菜の花台を通ってヤビツ峠まで、**途切れずにつながった1本の道**として走れるようにする。

- ユーザーの最終目標は、国道246号（秦野・名古木）から宮ヶ瀬までを1本の道で走れること。S2 はその2区間目。区間を足すたびに作り直しが積み重ならない形にする
- 重視することは S1 と同じ：道の線形・高低差・道幅の正確さ。見た目は「シンプルな形で、配置と色は実物に寄せる」（S1 の菜の花台・峠と同じ程度）
- ユーザーは Blender・コース制作の初心者。手作業は渡さず、Claude が自動で作り、ユーザーは走って確かめる（Street View の地点選びはユーザーが好んでやっている）

## 2. ユーザーが決めたこと

| 項目 | 決定 |
|---|---|
| 道 | 蓑毛のバス停 → 菜の花台 → ヤビツ峠の先まで、1本につながった道。どのレイアウトでも、ゴールの先も道が続いていて走っていける |
| S2 上り | 蓑毛のバス停でスタート → 菜の花台でゴール（タイム計測はここまで）。ゴール後も峠まで走れる |
| S2 下り | 菜の花台でスタート → 蓑毛でゴール |
| S1 上り／下り | 今のまま残す（同じ1本の道の上で選べる） |
| 蓑毛のバス停まわり | 菜の花台・峠と同じくらいの細かさで作り込む（バスの折り返し場、まわりの家、お堂、橋など） |
| 木・森の見た目 | 全区間ができてからの仕上げに回す（S2 でも作り込まない） |
| スタート・ピット・計測位置 | S1 では、ユーザーが Street View で地点を選んだ（下りスタート・ピット）。S2 でも同じやり方で確かめる |

## 3. 下調べで分かったこと（2026-10-17、OSM・地理院・Street View）

| 項目 | 値 |
|---|---|
| 区間 | 蓑毛バス停（OSM node 1312645669、35.4157193, 139.2283963）→ 菜の花台のヘアピン（S1 の始点） |
| 長さ | 約 4.1km（OSM の県道70号に沿って 4,070m） |
| 標高 | 約 319m → 562m（+243m、平均 約6%） |
| 橋 | OSM で7か所（ほとんど沢をまたぐ短い橋と思われる。バス停のすぐ先に1つ） |
| 家・建物 | 蓑毛の最初の 約300m だけ。その先は S1 と同じ山道（杉林・ブロック擁壁・ガードレール・赤い滑り止めのヘアピン） |
| 路面の特徴 | 出だしの急坂に、丸い滑り止め模様のコンクリート舗装の区間がある |
| 菜の花台でのつながり方 | S2 の道は菜の花台のヘアピンの「下側の枝」から入ってきて、S1 の道の始点（ヘアピンの頂点）につながる |
| バス停まわり | 住宅地。バスの折り返し場（広場）、木造の小さなお堂、石碑、横断歩道、コンクリート欄干の小さな橋 |

## 4. 作るもの

### 4.1 1本の道としてつなぐ（構造の変更）

- 道の中心線は、**蓑毛のバス停の少し手前（下側）から峠の先まで**を1本で作る。下り（S2 下り）のゴールの先にも道が少し続き、上り（S2 上り）のスタート列の後ろに4台並べられるようにする（峠側と同じ考え方。目安：バス停の手前 約50m）
- **区間ごとの手作業データ（道幅・擁壁・ガードレールなどの表）は、区間ごとのファイルのまま**にする。距離は「その区間の始点からの距離」で書く。S1 の表（`data/manual/s1_*.csv`）は書き換えない
  - 理由：あとで S3（名古木側）を下に足しても、既存の表の距離がずれない
  - 区間の境目は緯度経度の地点で決める（S2/S1 の境目＝S1 の始点 `config.S1_START` 付近のヘアピン）
- 駐車場・広場・スタート・ピット・計測位置は、**緯度経度で位置を決める**（峠まわり `s1_pass.json` と同じ）。道の距離には頼らない
- 菜の花台の駐車場（`start_lot.py`）は、今は「道の始まりにある駐車場」を前提にしている（スタート側の駐車場を差し替える、道の始まり 0〜80m の範囲と重ならないよう削る）。**道の途中にある駐車場**として扱えるように直す
- 地形・木・ゲーム用ファイル（kn5）は、つながった道全体でまとめて作る。区間の境目に地形の重なりやすき間、路面の段差を作らない
- S1 の見た目・走り（道の位置・高さ・壁・菜の花台・峠まわり）は変えない

### 4.2 S2 の道

S1 と同じ手順で作る（OSM の中心線 → 空中写真で位置確認 → 地理院の標高で高さ → 道幅 → 地形 → 擁壁・ガードレール → 木）。

- **道幅・擁壁・ガードレール**：S1 と同じく Claude が Street View を約50m ごとに見て決め、結果をユーザーに見せて OK をもらってから反映する
- **橋**：標高データは当てにならないので、前後の高さから補間する（S1 と同じ）。見た目は、Street View で確かめた欄干（コンクリートなど）を両側に付ける
- **滑り止め舗装**：赤い滑り止め（ヘアピン）と、丸い模様のコンクリート舗装の区間を、Street View で場所を確かめて路面の色・模様を変える（形はシンプルでよい）

### 4.3 蓑毛のバス停まわり

菜の花台・峠と同じ程度の細かさ（シンプルな形、配置と色は実物に寄せる）。

- バスの折り返し場（舗装の広場）
- まわりの家：道から見える範囲の家を、白っぽい壁＋三角屋根の箱で置く（場所と大きさは OSM の建物データか空中写真から）
- 木造の小さなお堂、石碑
- バス停すぐ先の橋（欄干付き）、横断歩道
- やらないこと：電柱・電線、看板・標識、カーブミラー、塀や植え込みの細かい形

### 4.4 レイアウト（コースの選び方）

| レイアウト | スタート | 計測開始 | ゴール | ピット |
|---|---|---|---|---|
| S2 上り（新） | 蓑毛のバス停付近（4台） | スタートの少し先 | 菜の花台（S1 上りのスタートより手前） | 蓑毛のバス停まわり（折り返し場など） |
| S2 下り（新） | 菜の花台（ヘアピンの下側の枝、4台） | スタートの少し先 | 蓑毛（バス停付近） | 菜の花台の駐車場 |
| S1 上り | 今のまま | 今のまま | 今のまま | 今のまま |
| S1 下り | 今のまま | 今のまま | 今のまま | 今のまま |

- 具体的な地点は Claude が案を出し、ユーザーが Street View で確かめて決める（変更があれば緯度経度で受け取る）
- AI 用の走行ライン（`fast_lane.ai`）は、どのレイアウトも道全体を対象に、レイアウトの向きで作る
- ミニマップ・カメラ・`ui_track.json`（出典表記つき）もレイアウトごとに作る

## 5. やらないこと（後の段階に回す）

- 木・森の作り込み（全区間ができてからの仕上げ）
- S3（名古木 → 蓑毛）、S4・S5（峠 → 宮ヶ瀬）
- 夜間照明・雨などの CSP 設定、音
- 電柱・看板・標識・カーブミラーなどの細かい物

## 6. 完成の条件（受け入れ基準）

S1 の基準（位置 約2m以内、高さ ±1.5m 以内、不自然な段差なし、完走・計測・壁すり抜けなし、カクつかない、見た目に違和感なし）を S2 にも当てはめ、さらに次を満たすこと。

| 観点 | 基準 |
|---|---|
| つなぎ目 | 菜の花台の境目で、路面の段差・折れ・地形のすき間がない。上りも下りも、そのまま走り抜けられる |
| S1 が変わっていない | S1 上り／下りのスタート・ピット・計測位置と、菜の花台・峠まわりが今と同じ場所にある（緯度経度で比べる） |
| 4つのレイアウト | S2 上り・S2 下り・S1 上り・S1 下りのどれでも、スタートからゴールまで走れてタイムが出る。AI 車も完走する |
| 動作 | 道が倍以上の長さになっても、ユーザーの PC でカクつかない（S1 では未確認なので、S2 で一緒に確かめる） |

## 7. 想定されるリスクと対策

| リスク | 対策 |
|---|---|
| つなぎ目で道の形が S1 と少し変わる（なめらか化を1本でやり直すため） | S1 の区間の位置・高さが今と変わらないことを、緯度経度と標高で比べて確かめる |
| ゲーム用ファイルが重くなる（S1 で 65MB／3.3km） | 必要なら kn5 を複数に分ける。FPS をユーザーに確かめてもらう |
| OSM の建物データが取れない（Overpass が混雑） | 予備のサーバーを使う。取れなければ空中写真から測る |
| 蓑毛の家の数が多く、手間がかかる | 道から見える範囲（道から 約40m 以内）に絞る |

## 8. Claude の判断で決めたこと（読む人のレビュー後に追記）

- **S1 の道がどれだけ変わってよいか**：つなぎ目（菜の花台のヘアピン、S1 の始点から 約30m まで）は、ヘアピンの前半が新しく加わるので形が変わってよい。それより先の S1 は、道の中心の位置・高さとも今と 0.1m 以内にそろえる。S1 のスタート・ピット・計測位置と、菜の花台・峠まわりは緯度経度で比べて確かめる
- **動作（カクつき）の確認を先にやる**：S1 の FPS はまだ確かめていない。S2 を作り始める前に、ユーザーに S1 を走ってカクつきがないか見てもらう。カクつくなら、地形や kn5 の大きさの上限を最初から組み込む

## 9. Claude に任せること

- プログラムの組み立て方（区間の表をどうつなぐか、ファイルの分け方など）。ただし 4.1 の決まりは守る
- 道幅・擁壁などの細かい値、家の大きさ、滑り止め舗装の模様
- スタート・ピット・計測位置の最初の案（最終決定はユーザー）
