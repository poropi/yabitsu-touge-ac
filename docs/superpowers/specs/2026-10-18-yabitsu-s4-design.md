## 1. 目的と、なぜこの形か

ヤビツ峠から宮ヶ瀬側へ下る県道70号を、今の道（名古木 → 峠）に**途切れずにつなげて**走れるようにする。最終目標「名古木 → 宮ヶ瀬北原交差点」の前半（峠 → 札掛）。後半の S5（札掛 → 宮ヶ瀬北原）はこの次に作る。さらに将来は、宮ヶ瀬北原から県道64号で鳥居原ふれあいの館まで延ばす予定がある。

- ユーザーの一番の要望：**「全て」を再現する**。見える所だけでなく、コースから半径 200m は見えない所も含めて、地図・空中写真・ストリートビューのとおりに作る（S3 と同じ細かさ）
- 道の線形・高低差・道幅の正確さは S1〜S3 と同じく最重要
- ユーザーは初心者。手作業は渡さず、Claude が自動で作る。ユーザーは走って確かめる。直したところは、直す前・直したあと・ストリートビューを並べた画像で見せる

## 4. 作るもの

### 4.1 S4 の道（S1 の先につなぐ）

S1〜S3 と同じ手順で作る（OSM の中心線 → 空中写真で位置確認 → 地理院の標高で高さ → 道幅 → 地形 → 擁壁・ガードレール・歩道 → 中央線・路面の模様）。

- `config.SECTIONS` の最後に S4 を足す（並びは名古木から：s3 → s2 → s1 → s4）。区間ごとの表は `data/manual/s4_*.csv` に新しく作る。S1〜S3 の表は書き換えない
- 峠のつなぎ目（`S1_END`）で段差・折れなし。S1〜S3 の道（位置・高さ・見た目・スタート・ピット・計測位置）は変えない。つなぎ目から 約30m より手前は今と 0.1m 以内（S1 の回帰テストで確かめる）
- 道幅・擁壁・ガードレール・路肩・中央線・路面の模様：ストリートビューを 約50m ごとに見て決め、空中写真でも確かめる。ストリートビューで見えない所は空中写真で決める（S3 で合意した見方）
- 橋：15か所すべて、欄干（または柵）つきで。長さと位置は OSM と空中写真。橋の下に川・沢があれば谷と水面を作る（4.3）
- 道ぞいの物：カーブミラー、道路標識、視線誘導標、落石注意などの看板、退避所（道が広くなる所）、駐車できる広場、湧き水の水くみ場など、ストリートビューで見えるものは置く。電柱・電線は今まで通り後回し

### 4.2 分かれ道（柵の先も道として作る）

- S4 の分かれ道（車が入れる道。OSM の `highway=track` の林道も含む）を、**入口から 200m 以内（道がそれより短ければ終わりまで）、地図の線どおりの道として作る**。道幅と路面はストリートビュー・空中写真で決める（見えない所は OSM の道の種類から）
- 入口には今まで通り、工事中の柵と見えない壁を置く（本線と歩道・横断歩道から 1m 以上離す。S3 で決めた置き方）。柵と見えない壁は**別の部品**にして、外せば奥へ走れるようにしておく（外すしくみ自体は作らない）
- 分かれ道の奥の終わり（200m の所）には見えない壁を置く
- 山道・遊歩道（path・footway・steps）は、見た目の道として地形の上に描く（走れない）

### 4.3 川・沢・滝・湧き水

- OSM の川・沢（`waterway=river|stream`）のうち、コースから 200m 以内のものを、地形の谷の底に**水面と川原（石の帯）**として作る。水面の高さは標高データの谷底に合わせ、下流へ向かって必ず下がるようにする
- 橋の下では、水面が橋の桁より下を通ること、道の路面や地形が水面にかぶらないことを確かめる
- 滝・砂防ダム（川の段差）：ストリートビューと空中写真で見えたものを、場所と高さを合わせて置く（水の落ちる面＋段差のコンクリート）
- 護摩屋敷の水：水くみ場（屋根・水場）をストリートビューで確かめて作る
- 水は動かさない（流れる動きは作らない）

### 4.6 重さ（ゲーム用ファイル）の分け方

- 今は `yabitsu_main.kn5`（202MB）に S1〜S3 の道と景色、`yabitsu_nagoki.kn5`（51MB）に名古木の町が入っている
- S4 の道・景色・建物・川は、新しい `yabitsu_s4.kn5` に入れる（1つのファイルが大きくなりすぎないように）
- 峠の北の地形は今 `yabitsu_main.kn5` にも入っているので、S4 の道の所は main の地形から抜き、`yabitsu_s4.kn5` で埋める。そのため**今の8つのレイアウトも含めて、全部のレイアウトが `yabitsu_s4.kn5` を読む**（Claude の判断、8 章）。今の8つは、走り方・スタート・ピット・計測位置が今と同じで、峠の北の景色だけが本物の S4 になる
- 重さはユーザーの試走で確かめる。カクつくようなら、遠くの景色を軽くする・区間ごとに読むファイルを分けるなどを、そのとき決める

### 4.7 将来の延長（S5・鳥居原）への備え

- 区間の始まり・終わり・広場・ピットなどは、距離ではなく緯度・経度で決める（今まで通り）
- S4 の終わり（札掛）は、S5 の道がそのまま続けられる形で終える（道の終わりの先に、見えない壁と工事中の柵だけを置く）
- 宮ヶ瀬北原交差点（S5 で作る）は、鳥居原へ向かう県道64号の口も地図どおりの道として作り、柵でふさぐ。延長のときは柵を外して道をつなげればよいようにする（S5 の設計で詳しく決める）

## 5. やらないこと（後の段階に回す）

- 木・森の作り込み、電柱・電線、路面の矢印・「止まれ」などの文字（全区間の仕上げ）
- S5（札掛 → 宮ヶ瀬北原）、鳥居原への延長
- 分かれ道の柵を外すしくみ（ゲームの中で切り替える機能）。部品を分けておくところまで
- 水の流れる動き、音、ほかの車や人、夜・雨の設定
- S3 の試走で出た細かい指摘（ユーザーがまとめて伝えたら別に直す）

## 6. 完成の条件（受け入れ基準）

S1〜S3 の基準（道の位置が空中写真と約2m以内、高さが標高データと ±1.5m 以内（橋を除く）、不自然な段差なし、完走・計測・壁すり抜けなし、カクつかない、見た目に違和感なし）を S4 にも当てはめ、さらに次を満たすこと。

| 観点 | 基準 |
|---|---|
| つなぎ目 | 峠（`S1_END`）で段差・折れなし。S1〜S3 の回帰テストが通る |
| 道の上に何も出ない | 地形・川・建物・柱・目印が、路面と歩道の上に出ない（S3 で作った「地面が路面の 10cm 以内」の調べで 0か所） |
| 分かれ道 | 柵の先が 200m（または道の終わり）まで道として作られ、柵の先へは車で出られない。柵と見えない壁を消せば、その道を走れる形になっている |
| 川 | 橋の下を川・沢が通り、水面が下流へ下がる。水面が路面や橋にかぶらない |
| 見た目 | ストリートビュー（約50m ごと）と並べて違和感がない。ユーザーの走行で OK |
| レイアウト | 新しい4つと今の8つのどれも、スタートからゴールまで走れてタイムが出る。今の8つは走り方・スタート・ピット・計測位置が今と同じ（峠の北の景色は S4 になる） |
| 動作 | どのレイアウトでもカクつかない（ユーザーの PC。全部のレイアウトが S4 のファイルも読むため） |

## 7. 想定されるリスクと対策

| リスク | 対策 |
|---|---|
| S4 を足すと、今の区間の高さの合わせ直しで S1 がずれる | 高さは区間ごとに 1m 格子で合わせ直す作り（`elevation.fit_sections`）。S1〜S3 の回帰テストで、ずれたらすぐ分かる |
| 山の中で空中写真が木に隠れ、道の位置・幅が分からない | OSM の線を基本に、ストリートビューの撮影位置（道の上の点）で位置を確かめる。見えない所はまわりの値をつなぐ |
| 川の水面が地形の粗さ（5m 標高）でガタガタになる・上流へ上がる | 川の線に沿って谷底の高さを取り、下流へ向かって単調に下がるようにならす。橋の所では桁の下に収める |
| 分かれ道を 200m 作ると、地形との合わせ（土台）が増えて作り直しが遅くなる | 分かれ道の土台は S3 と同じ「傾いた平面の土台」を使い、地形を動かす範囲を道のまわりに限る |
| ファイルが重くなる | S4 を別の kn5 にする（4.6）。全部のレイアウトが読むので、試走でカクつきを確かめ、出たら遠くの景色を軽くする |

## 8. Claude の判断で決めたこと

- S4 の終わりは、札掛橋の北の端から県道70号に沿って 250m 先。札掛の分かれ道・広い所・S4 上りのスタートとピット・S4 下りのゴールのあとに止まる長さを、S4 の中に収めるため。S5 はそこから続ける（作る人の目での確認で、橋の所で終えると上りのスタートとピットが区間の外になる食い違いが見つかったため）
- 全線のレイアウトは、今の「全線 上り／下り（名古木 ⇄ 峠）」はそのまま残し、「名古木 → 札掛」「札掛 → 名古木」を新しく足す（今のレイアウトの意味を変えないため）
- S4 は別の kn5（`yabitsu_s4.kn5`）にし、全部のレイアウトがこれを読む（峠の北の地形を S4 の道で置きかえるので、読まないレイアウトでは穴に見えてしまうため）。今のレイアウトの意味は変えないが、峠の北の景色は変わる
- 分かれ道の奥行きは 200m（または道の終わり）。奥の終わりには見えない壁。OSM の `highway=track`（林道）も車が入れる分かれ道として作る（「全て」と「柵を外せば走れる」に合わせるため）
- 峠のつなぎ目は、S1 の高さを変えずに S4 の高さを S1 にすりつける（S1 の最後の部分を合わせ直さない）
- 川・沢は 200m 以内のものだけ。水面は動かさない

## 9. Claude に任せること

- プログラムの組み立て方（分かれ道を長く作る作り、川の作り、ファイルの分け方など）。ただし 4.2 の「柵と見えない壁は別の部品」と、今の8つのレイアウトの走り方・スタート・ピット・計測位置を変えないことは守る
- 道幅・擁壁・路肩などの細かい値、建物の細かい形と色、レイアウトの地点
