# S3（名古木→蓑毛）道路まわりの仕上げ 設計

2026-10-19。ユーザー：「コースの道路周りをリアルなイメージにしてほしい」「名古木から蓑毛までの下界と、蓑毛以降の山道だと見た目も変わってくる」「路面、コース上のガードレール、コンクリートの壁、その他オブジェクトを実際の写真を見ながら合わせていってほしい」「まずはS3から」。どこが作り物っぽいかの問いには「何もやっていないので、全てです！」と答えた。

## 目的

S3 を走ったとき、日本の郊外の県道（下界）に見えるようにする。今は路面・壁・柵が単色に近く、種類（間知石の石積み、ブロック塀、コンクリート擁壁、ガードパイプなど）が `data/manual/s3_features.csv` に記録されているのに、見た目に反映されていない。

## 対象（全部）

- **路面**：アスファルトの質感、つぎはぎ・ひび・補修跡、白線・中央線のかすれ、マンホール・排水ます。
- **ガードレール類**：表の種類どおりの形（白いガードパイプ、波形ガードレール、橋の手すりなど）。支柱・反射板も付ける。
- **壁**：間知石の石積み、ブロック塀、コンクリート擁壁を作り分ける（目地、汚れ、水抜き穴、苔）。
- **路肩・歩道**：縁石、歩道の舗装、側溝（U 字溝とふた）。
- **その他**：電柱と電線、カーブミラー、標識など、下界らしさを出すもの。

## やらないこと

- S2 以降（蓑毛から先の山道）。S3 の作り方ができてから、山道向けの見た目で別に行う。
- 建物そのもの、森（済み）。
- 走る面・壁の当たり判定の変更（走り心地を変えない）。

## 決まっていること

- **ユーザー**：実際の写真を見ながら合わせる。テクスチャを使ってよい。テクスチャが必要なら、画像は Codex に依頼する（Codex CLI の image_generation。`codex exec` で頼む）。
- **ユーザー（以前から）**：コースの kn5 は作り直さない（記憶 feedback-batch-rebuilds）。AI の使用量を抑える。機械的にできる所はスクリプトで一気に。見た目を直したら、同じ視点の画像を写真と並べて見せる（記憶 feedback-verify-with-screenshots）。画像はビューアーで開いて見せる。CSP 前提でよい。

## Claude が決めたこと

1. **写真**：ストリートビューを S3 全体で 100 m ごと、上り・下りで取り直す（約 90 枚。以前の撮影地点 `.superpowers/sdd/2026-10-17-yabitsu-s3/spots*.json` の pano と `sv_fetch.py` を使う）。種類ごとの見本帳（1 枚に数枚）にして見る。写真は見るだけで、ゲームの画像には使わない。
2. **作り方は森と同じ「上乗せ」**：S3 の見た目用の部品を別の kn5（`yabitsu_s3_dress.kn5`）にして、全レイアウトの models ini に1行足す。今の kn5 の S3 の見た目（路面・壁・柵の表示）は CSP の設定で隠す。当たり判定はそのまま（隠すのは表示だけ）。路面は、CSP で今の路面メッシュに新しいテクスチャを貼れるならそうし、できなければ同じ形の表示用メッシュを上乗せする（作る人が確かめて決める）。
3. **データから機械的に作る**：種類と範囲は `s3_features.csv`・`s3_widths.csv`・`s3_pavements.csv`・`s3_objects.json` と、実際の道路の形（manifest）から。写真で表と違う所が見つかったら表を直す（場所ごとの手作業でなく、表の行を直してスクリプトを走らせ直す）。
4. **テクスチャ**：アスファルト（町用）、白線かすれ、間知石、ブロック塀、コンクリート擁壁、縁石・歩道、側溝ふた、などを Codex に生成依頼する。継ぎ目なく並べられること（シームレス）、実寸（1 枚が何 m 分か）を指定し、法線用の凹凸も頼む。届いたら自分で並べて確かめ、合わなければ指示を直して頼み直す。
5. **電柱と電線**：写真で見えた側と間隔を区間ごとに表へ書き、機械的に並べる（OSM には電柱がほとんどない）。
6. **確認**：写真の地点のうち 6 か所ほどで、ストリートビューと同じ視点の描画を並べた見比べ画像を作る。最後にユーザーに S3 を走ってもらう。
7. **ext_config.ini**：森と S3 の仕上げの両方が書くので、部分ごとに組み立てて1つのファイルにする（森の部分を消さない）。
8. 作業ブランチは森（`feat/forest`）の上に作る（森の main への取り込みはユーザーに確認する）。

## 作る人に任せること

部品の細かさ（三角形数）、テクスチャの解像度、CSP の設定の書き方、電柱の間隔の既定値、見本帳の作り方。
