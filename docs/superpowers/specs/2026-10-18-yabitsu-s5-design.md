## 1. 目的と、なぜこの形か

札掛から宮ヶ瀬湖ぞいを通って、県道70号の終わり（宮ヶ瀬北原交差点）までを、今の道（名古木 → 札掛）に途切れずにつなげる。これで最終目標「名古木 → 宮ヶ瀬北原交差点」の1本の道（約 29.9km）ができる。将来は宮ヶ瀬北原から県道64号で鳥居原ふれあいの館（35.538915, 139.222051、約 3.4km）まで延ばす。

- 方針は S4 と同じ：**「全て」を再現**（地図・空中写真・ストリートビューのとおり。コースから半径 200m は見えない所も含めて作る。木は最後の仕上げ）
- 道の線形・高低差・道幅の正確さは最重要。S4 の試走で分かった「標高データの谷・土手を道の高さにしない」ことを守る
- ユーザーは初心者。手作業は渡さない。直したところは、直す前・直したあと・ストリートビューを並べた画像で見せる

## 4. 作るもの

### 4.1 S5 の道（S4 の先につなぐ）

- `config.SECTIONS` の最後に S5 を足す。表は `data/manual/s5_*.csv`
- 高さ：`elevation.fit_sections(..., fixed=3, robust=True)` のまま（S4 の高さは1mmも変わらない）。標高データの短い谷・土手は道の高さにしない。トンネルの中は標高データ（山の表面）を使わず、坑口どうしを結ぶ（橋と同じく外す）
- S4 の終わりの工事中の柵と見えない壁（`assembly.road_end_closure`）は外し、S5 の終わり（交差点）は 4.3 の作りで閉じる
- 道幅・擁壁・ガードレール・路肩・中央線・路面の模様・退避所・広場・カーブミラー・標識：S4 と同じく 50m ごとのストリートビュー（両向き）と空中写真で決める
- S1〜S4 の道（位置・高さ・見た目・スタート・ピット・計測位置）は変えない。札掛のつなぎ目 30m より手前は今と 0.1m 以内（S4 の回帰テストを作って確かめる）

### 4.2 名前のある所の作り込み

- **トンネル（3 か所、特に吹風トンネル）**：坑口（コンクリートの面・アーチ・トンネル名の表札）、内側の壁と天井（アーチの断面）、照明（列になったランプ、点灯は固定）、路面・側溝。トンネルの上は地形（山）でふさぐ。中は暗く、外の地形・木は描かない。形・色・表札の文字はストリートビューで確かめる
- **橋（名前のある 15 か所）**：欄干・手すりの形と色、親柱と橋の名前の銘板（文字まで）、橋桁と橋脚（湖・谷の上の大きな橋）。**大門桟道**は崖に張り出した形（支え）で作る。すべてストリートビューと空中写真で確かめる
- **川（中津川・本谷川・唐沢川・布川）**：S4 の `water.py` で水面と川原。名前のある川は、橋から見える所の川原の石・岩、砂防ダム・堰（あれば）をストリートビューで確かめて作る
- **宮ヶ瀬湖**：湖面を平らな水面として作る（水位は空中写真・標高データの湖岸の高さから決め、記録する）。道から見える湖の全体に張る（200m で切ると、湖のまん中で水が途切れて見えるため。作る人の目での確認の提案、Claude の判断）。岸は地形と合わせる
- **滝**：OSM の滝と、ストリートビュー・空中写真で見えた滝を、S4 の `water.feature_meshes` の作りで

### 4.3 ゴール：宮ヶ瀬北原交差点（半径 200m）

名古木交差点（S3 の `town.py`）と同じ作り方にする（Claude の案、ユーザー確認済み）。

- 交差点の中心から半径 200m の道を、OSM の線と空中写真で地図どおりに作る（車道・歩道・縁石・角の丸み）。横断歩道・停止線・車線の線・中央線、信号（灯火は固定）、バス停「三又路」2 か所
- 建物は 1 棟ずつストリートビューで確かめる（形・高さ・屋根・色・看板。店名の文字と色まで、ロゴなし）
- 県道70号以外の道（県道64号の両方向、そのほかの道）は**道として作り**、入口（横断歩道の外側）に工事中の柵＋見えない壁。柵と壁は別の部品
- **県道64号の鳥居原方面**は、将来つなげる道。入口の柵の先も 200m の範囲いっぱいまで道として作り、柵を外して先へ延ばせばよいようにする
- 町の範囲の部品は別の kn5（名古木と同じ考え方。`yabitsu_kitahara.kn5`）

### 4.4 分かれ道・建物・道ぞいの物

S4 と同じ：車の入れる分かれ道（林道を含む）は柵の先 200m まで道に（入口の柵・入口の壁・奥の壁は別の部品）。建物は 200m 以内を全部、道から見えるものはストリートビューで1棟ずつ。キャンプ場・霊園・展望地の看板や設備も。

## 5. やらないこと

- 鳥居原への延長そのもの（県道64号の先）、宮ヶ瀬ダム・湖の遠くの景色の作り込み
- 木・森、電柱・電線、路面の文字、水の流れる動き、トンネルの照明の点滅、音、ほかの車・人、夜・雨
- S4 の最終レビューで残した小さな点（`docs/s4-acceptance.md`）

## 6. 完成の条件

S1〜S4 の基準（位置 2m、高さ ±1.5m（橋・トンネル・標高データの谷を除く）、段差・うねりなし（20m ごとの曲がりが S1〜S4 と同じくらい以下）、完走・計測・壁すり抜けなし、カクつかない、見た目に違和感なし、`road_clear`＝0）を S5 にも当てはめ、さらに：

| 観点 | 基準 |
|---|---|
| つなぎ目 | 札掛で段差・折れなし。S1〜S4 の回帰テストが通る（S4 の参照を新しく作る） |
| トンネル | 中を走れて、壁をすり抜けない。坑口と中が明るさ・形とも違和感がない。トンネルの上の地形に穴がない |
| 名前のある橋・川 | ストリートビューと並べて、形・色・銘板が「同じ橋」と分かる。水面は下流へ下がり、路面にかぶらない |
| 湖 | 湖面が平らで、岸の地形とすき間・重なりがない |
| 交差点 | 名古木と同じ基準（道の線 1m、封鎖の柵の先へ出られない、建物が同じ建物と分かる）。県道64号の鳥居原方面の柵を外すと先の道へ出られる形 |
| レイアウト | 新しい4つと今の12個がスタートからゴールまで走れてタイムが出る。今の12個は同じ |

## 7. 想定されるリスクと対策

| リスク | 対策 |
|---|---|
| トンネルは今までにない部品（本線の帯が地形の中を通る） | 地形はトンネルの範囲だけ帯の下へ下げず、帯の上に「山」を残す。坑口で地形と壁をつなぐ。描画で中と外を確かめる |
| 湖岸の高い橋が続き、標高データ（湖面・谷）を拾って高さが崩れる | 橋・トンネル・谷は外して補う（S4 の robust）。大きな橋の前後は、坑口や橋の端の高さを結ぶ |
| OSM の湖が relation で、今のキャッシュにない | relation を取り直し、外周と島を多角形にする |
| ファイルが大きくなる | S5 と交差点を別の kn5 に。試走で確かめる |
| 交差点の作りを名古木から流用するとき、名古木の決まり（`config.NAGOKI` など）が埋め込まれている | 町の範囲を「中心・半径・spec ファイル」を渡して作れるようにしてから使う（名古木の結果は変えない） |

## 8. Claude の判断で決めたこと

- S5 は 1 区間（約 11.7km）で作る
- 交差点の町の kn5 を名古木とは別にする（`yabitsu_kitahara.kn5`）
- トンネルの中は標高データを使わない
- 湖の水位は1つの値（平らな水面）。湖面は道から見える湖の全体に張る
