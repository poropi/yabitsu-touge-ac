# S2（蓑毛 → 菜の花台）実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 蓑毛のバス停の下から峠の先までを1本の道にし、S2 上り／下りのレイアウトを足す。S1 は変えない。

**Architecture:** 区間（S2・S1）ごとに OSM の道をつないで1本の中心線を作り、高さは区間ごとに合わせてから境目でなめらかにつなぐ。手作業の表は区間ごとのファイル（区間の始点からの距離）のまま、読み込むときに通しの距離へずらす。スタート・ピット・計測位置は `data/manual/layouts.json` に緯度経度で書き、駐車場・広場は名前で指す。前半（Task 1〜5）は区間を S1 だけにして作り替え、S1 が変わらないことを確かめてから、後半で S2 を足す。

**Tech Stack:** Python 3.12（uv）、numpy・scipy・shapely・pyproj・Pillow、pytest、Blender 5.2（確認用の描画だけ）、Playwright（Street View の画像取得）、自前の kn5 書き出し（`yabitsu/kn5.py`）

**Spec:** `docs/superpowers/specs/2026-10-17-yabitsu-s2-design.md`（全体構成は `2026-10-17-yabitsu-s1-design.md`）

## Global Constraints

- `content/tracks/nanohanadai` には書き込まない（書き込みは必ず `config.assert_writable` を通す）
- 座標は EPSG:6677、原点はヤビツ峠（`geo.py`）。スタート・ピット・計測位置・駐車場・広場は緯度経度で決め、通しの距離 s には頼らない
- `data/manual/s1_*.csv` は書き換えない。区間の表の距離は「その区間の始点からの距離」
- S1 の道：S1 の始点から 30m より先は、中心の位置・高さとも今と 0.1m 以内。S1 上り／下りのスタート・ピット・計測位置、菜の花台の駐車場・展望台、峠まわりは今と同じ場所
- ゲーム用ファイルは `scripts.make_kn5` で直接書く（ksEditor は使わない）。出典表記は `CREDITS`（`出典：国土地理院（標高タイル・シームレス空中写真）／© OpenStreetMap contributors (ODbL)`）
- リポジトリのファイルは LF で書く（Python の `write_text` は `newline="\n"` を付ける）。AC 用の ini・json は `acdata.write_text`（CRLF）のまま
- スクリプトは `uv run python -m scripts.<name>`、テストは `uv run pytest -q`
- 木・森の見た目は作り込まない（全区間ができてからの仕上げ）
- ユーザーに手作業を渡さない。ユーザーの番は「走って確かめる」「Street View で地点を選ぶ・結果を見て OK を出す」だけ

## Review Focus

1. **菜の花台の2本の枝の取り違え**：ヘアピンの上の枝（S1）と下の枝（S2）は 約13m しか離れていない。緯度経度から s を求めるとき、もう一方の枝を拾うとスタート列が別の道に立つ → `layouts.s_of` は区間を指定して、その区間の中だけで探す（Task 4 のテスト）
2. **つなぎ目の折れ・段差**：ヘアピンの頂点で向き・高さ・勾配が飛ぶと、走ると突き上げる → Task 6 のテスト（向きの変化と勾配の変化の上限）
3. **菜の花台の駐車場と下の枝の重なり**：駐車場の北東の端は S2 の下の枝に近い。道の範囲を削り忘れると路面が二重になる → Task 4 のテスト
4. **蓑毛の家の土台**：家は道から離れた斜面にも建つ。道に合わせた1枚の平面で高さを決めると、浮くか埋まる → 家ごとに地面の高さで平らにする（Task 9 のテスト）
5. **古いファイルの残り**：`yabitsu_s1.kn5` などが残ると、コースフォルダが重く紛らわしい → Task 11 で消し、`models_*.ini` が新しい kn5 だけを指すことを確かめる
