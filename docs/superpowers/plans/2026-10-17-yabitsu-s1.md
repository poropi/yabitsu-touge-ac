# ヤビツ峠 S1（菜の花台 → ヤビツ峠）実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 公開データ（国土地理院・OpenStreetMap）から S1 区間（約3.3km、562m → 760m）を自動生成し、Assetto Corsa で上り・下りの2レイアウトとして走れる新コース `yabitsu` を作る。

**Architecture:** データ処理はすべて作業用フォルダの Python（uv 環境）で行い、メッシュを頂点・面の配列（`.npz`）と一覧ファイル（`manifest.json`）に書き出す。Blender 側のスクリプトは manifest を読んでオブジェクトを作り FBX に書き出すだけにする（Blender に pyproj などを入れない）。FBX → kn5 の変換はユーザーが ksEditor で行い、AC 用の設定ファイル（ini / json / map）は Python で生成する。

**Tech Stack:** Python 3.12（uv）、numpy / scipy / pyproj / shapely / requests / pillow / matplotlib / pytest、Blender 5.2（bpy・同梱 numpy・標準 FBX 書き出し）、ksEditor（AC SDK）、Content Manager ＋ CSP

**Spec:** `docs/superpowers/specs/2026-10-17-yabitsu-s1-design.md`

## Global Constraints

- `content/tracks/nanohanadai` は**読み取りも含めて作業対象にしない・絶対に書き込まない**。AC フォルダへの書き込みは必ず `yabitsu.config.assert_writable()` を通す。
- 既存MODの素材（モデル・テクスチャ）は流用しない。写真（空中写真・ストリートビュー）はテクスチャに使わず、位置合わせと見比べ専用。
- 出典表記：「国土地理院（標高タイル・シームレス空中写真）」「© OpenStreetMap contributors (ODbL)」をコースの `read_me.txt` と `ui_track.json` の description に入れる。
- 座標：JGD2011 平面直角座標系 第IX系（EPSG:6677）、水平原点 = ヤビツ峠（北緯35.42782°、東経139.21934°）、高さ = 標高そのまま（m）。Blender：X = 東、Y = 北、Z = 標高、1単位 = 1m。
- Blender で動くスクリプト（`blender_scripts/`）は標準ライブラリ・bpy・numpy だけを使う。`yabitsu` パッケージは import しない。
- 命名：物理（当たり判定）メッシュは `1ROAD_*` / `1GRASS_*` / `1WALL_*`。見た目だけのメッシュは数字で始めない（`LINES_*`、`TERRAIN_FAR_*`、`TREES_*`）。AC 用ダミーは `AC_*`。
- 1つのメッシュの頂点数は 65,535 以下（kn5 の制限）。`Manifest.add_mesh` で検査する。
- コースフォルダ `yabitsu`、レイアウト `s1_up`（菜の花台 → 山頂）と `s1_down`（山頂 → 菜の花台）。kn5 は `yabitsu_s1.kn5`、`s1_up_objects.kn5`、`s1_down_objects.kn5`。
- 各レイアウトとも、ピット4台分・スタート位置4台分。
- 受け入れ基準：道の位置は空中写真と約2m以内、道の中心の高さは標高データ（スパイク除去後、橋を除く）と ±1.5m 以内。
- テストは `uv run pytest`（作業用フォルダで実行）。テストはネットワークに接続しない。
- ユーザーは Blender・コース制作の初心者。ユーザー作業の手順は、日本語で一つずつ案内する。

## Review Focus

1. **保護フォルダへの書き込み**：設定ミスで出力先が `nanohanadai` を指しても、書き込まずにエラーで止まる（Task 1・Task 2 のテスト）。
2. **Overpass サーバーの混雑（502/504）**：次のサーバーに切り替えて取得し、一度取れたデータは保存して再利用する（Task 4 のテスト）。
3. **5mメッシュの欠損（nodata・タイル無し）**：10mメッシュで自動的に補い、標高プロファイルに穴（NaN）が残らない（Task 3・Task 6 のテスト）。
4. **道幅の半分より急なヘアピン**：路面メッシュが内側で折り返したら、その位置（s）を示してエラーで止まる（Task 10 のテスト）。
5. **下りレイアウトの向き**：スタート列・計測ゲート・ピットが逆向きにならず、走る方向に対してスタートがゴールより手前にある（Task 2・Task 15 のテスト）。

```python
class ProtectedPathError(RuntimeError):
    pass


def _norm(p) -> str:
    return os.path.normcase(os.path.abspath(p))


def assert_writable(path) -> Path:
    p = _norm(path)
    for d in PROTECTED_DIRS:
        dn = _norm(d)
        if p == dn or p.startswith(dn + os.sep):
            raise ProtectedPathError(f"{path} は変更禁止のフォルダ（{d}）の中です")
    return Path(path)
```

`yabitsu/geo.py`：

```python
import numpy as np
from pyproj import Transformer

ORIGIN_LAT, ORIGIN_LON = 35.42782, 139.21934  # ヤビツ峠
_fwd = Transformer.from_crs("EPSG:4326", "EPSG:6677", always_xy=True)
_inv = Transformer.from_crs("EPSG:6677", "EPSG:4326", always_xy=True)
_OX, _OY = _fwd.transform(ORIGIN_LON, ORIGIN_LAT)


def to_local(lat, lon):
    e, n = _fwd.transform(np.asarray(lon, float), np.asarray(lat, float))
    return e - _OX, n - _OY


def from_local(x, y):
    lon, lat = _inv.transform(np.asarray(x, float) + _OX, np.asarray(y, float) + _OY)
    return lat, lon
```

```python
import math
from dataclasses import dataclass

import numpy as np

# Task 2 の試験で確かめる値。結果は docs/ac-conventions.md に記録する。
DUMMY_YAW_OFFSET = math.pi / 2  # 空オブジェクトの -Y（Blender）が車の前方になる、という仮定
DUMMY_Z_OFFSET = 0.3            # 路面からの高さ（m）


@dataclass
class Dummy:
    name: str
    location: tuple
    heading: float  # 進行方向（ラジアン、+X から反時計回り）

    @property
    def rotation_z(self) -> float:
        return self.heading + DUMMY_YAW_OFFSET


def frame_at(path, s):
    S = path["s"]
    x = float(np.interp(s, S, path["x"])); y = float(np.interp(s, S, path["y"])); z = float(np.interp(s, S, path["z"]))
    c = np.interp(s, S, np.cos(path["heading"])); sn = np.interp(s, S, np.sin(path["heading"]))
    return x, y, z, math.atan2(sn, c)


def _place(path, s, direction, lateral):
    x, y, z, h = frame_at(path, s)
    hd = h if direction > 0 else h + math.pi
    nx, ny = -math.sin(hd), math.cos(hd)
    return (x + lateral * nx, y + lateral * ny, z + DUMMY_Z_OFFSET), math.atan2(math.sin(hd), math.cos(hd))


def start_grid(path, s0, direction, n=4, spacing=8.0, stagger=1.2):
    out = []
    for i in range(n):
        loc, hd = _place(path, s0 - direction * i * spacing, direction, stagger if i % 2 == 0 else -stagger)
        out.append(Dummy(f"AC_START_{i}", loc, hd))
    return out


def hotlap_start(path, s, direction):
    loc, hd = _place(path, s, direction, 0.0)
    return Dummy("AC_HOTLAP_START_0", loc, hd)


def timing_gate(path, s, direction, half_width, kind):
    out = []
    for side, lat in (("L", half_width), ("R", -half_width)):
        loc, hd = _place(path, s, direction, lat)
        out.append(Dummy(f"AC_OPEN_{kind}_{side}", loc, hd))
    return out


def pit_boxes(center_xy, z, heading, n=4, spacing=4.0):
    nx, ny = -math.sin(heading), math.cos(heading)
    out = []
    for i in range(n):
        lat = (n - 1) / 2 * spacing - i * spacing
        out.append(Dummy(f"AC_PIT_{i}", (center_xy[0] + lat * nx, center_xy[1] + lat * ny, z + DUMMY_Z_OFFSET), heading))
    return out
```

```python
import json
import shutil
from pathlib import Path

import numpy as np

MAX_VERTS = 65535


class Manifest:
    def __init__(self, root, reset=True):
        self.root = Path(root)
        if reset and (self.root / "meshes").exists():
            shutil.rmtree(self.root / "meshes")
        (self.root / "meshes").mkdir(parents=True, exist_ok=True)
        self.materials, self.meshes, self.empties, self.groups = {}, {}, {}, {}

    def _group(self, g):
        return self.groups.setdefault(g, {"meshes": [], "empties": []})

    def add_material(self, name, texture=None, color=None, alpha=False, two_sided=False):
        self.materials[name] = {"texture": texture, "color": color, "alpha": alpha, "two_sided": two_sided}

    def add_mesh(self, group, name, verts, faces, uvs, material, renderable=True):
        verts = np.asarray(verts, np.float64); faces = np.asarray(faces, np.int32); uvs = np.asarray(uvs, np.float32)
        if name in self.meshes or name in self.empties:
            raise ValueError(f"名前が重複しています: {name}")
        if len(verts) > MAX_VERTS:
            raise ValueError(f"{name}: 頂点数 {len(verts)} が上限 {MAX_VERTS} を超えています")
        if len(faces) == 0:
            raise ValueError(f"{name}: 面がありません")
        rel = f"meshes/{name}.npz"
        np.savez_compressed(self.root / rel, verts=verts, faces=faces, uvs=uvs)
        self.meshes[name] = {"file": rel, "material": material, "renderable": bool(renderable),
                             "verts": int(len(verts)), "faces": int(len(faces))}
        self._group(group)["meshes"].append(name)

    def add_empty(self, group, dummy):
        key = f"{group}/{dummy.name}"
        if key in self.empties:
            raise ValueError(f"名前が重複しています: {key}")
        self.empties[key] = {"name": dummy.name, "location": list(dummy.location), "rotation_z": dummy.rotation_z}
        self._group(group)["empties"].append(key)

    def save(self) -> Path:
        p = self.root / "manifest.json"
        p.write_text(json.dumps({"materials": self.materials, "meshes": self.meshes, "empties": self.empties,
                                 "groups": self.groups}, ensure_ascii=False, indent=1), encoding="utf-8")
        return p

    def summary(self) -> str:
        lines = []
        for g, c in self.groups.items():
            v = sum(self.meshes[n]["verts"] for n in c["meshes"]); f = sum(self.meshes[n]["faces"] for n in c["meshes"])
            lines.append(f"{g}: meshes={len(c['meshes'])} empties={len(c['empties'])} verts={v} faces={f}")
        return "\n".join(lines)
```

```python
import io
import math
import time
from pathlib import Path

import numpy as np
import requests
from PIL import Image

from .config import DATA_RAW

GSI_URL = "https://cyberjapandata.gsi.go.jp/xyz/{layer}/{z}/{x}/{y}.{ext}"
NA = 2 ** 23


def decode_dem_png(rgb):
    rgb = np.asarray(rgb).astype(np.int64)
    v = rgb[..., 0] * 65536 + rgb[..., 1] * 256 + rgb[..., 2]
    h = np.where(v < NA, v, v - 2 ** 24).astype(np.float64) * 0.01
    h[v == NA] = np.nan
    return h


def tile_coords(lat, lon, z):
    n = 2 ** z
    fx = (np.asarray(lon, float) + 180.0) / 360.0 * n
    fy = (1.0 - np.arcsinh(np.tan(np.radians(np.asarray(lat, float)))) / math.pi) / 2.0 * n
    return fx, fy


def _http_get(url):
    r = requests.get(url, timeout=30, headers={"User-Agent": "yabitsu-track-builder"})
    return r.status_code, r.content


class TileCache:
    def __init__(self, root=DATA_RAW / "gsi", fetch=None, delay=0.05):
        self.root, self.fetch, self.delay = Path(root), fetch or _http_get, delay

    def path(self, layer, z, x, y, ext):
        return self.root / layer / str(z) / str(x) / f"{y}.{ext}"

    def get_bytes(self, layer, z, x, y, ext):
        p = self.path(layer, z, x, y, ext)
        missing = p.with_name(p.name + ".missing")
        if p.exists():
            return p.read_bytes()
        if missing.exists():
            return None
        url = GSI_URL.format(layer=layer, z=z, x=x, y=y, ext=ext)
        status, content = self.fetch(url)
        if self.delay:
            time.sleep(self.delay)
        p.parent.mkdir(parents=True, exist_ok=True)
        if status == 404:
            missing.touch(); return None
        if status != 200:
            raise RuntimeError(f"国土地理院タイルの取得に失敗 ({status}): {url}")
        p.write_bytes(content)
        return content


class DemSampler:
    def __init__(self, cache, layer="dem5a_png", z=15):
        self.cache, self.layer, self.z, self._tiles = cache, layer, z, {}

    def _tile(self, tx, ty):
        k = (tx, ty)
        if k not in self._tiles:
            b = self.cache.get_bytes(self.layer, self.z, tx, ty, "png")
            self._tiles[k] = (np.full((256, 256), np.nan) if b is None
                              else decode_dem_png(np.array(Image.open(io.BytesIO(b)).convert("RGB"))))
        return self._tiles[k]

    def _pixels(self, gx, gy):
        tx, ty = np.floor_divide(gx, 256), np.floor_divide(gy, 256)
        px, py = gx - tx * 256, gy - ty * 256
        out = np.full(gx.shape, np.nan)
        for a, b in np.unique(np.stack([tx.ravel(), ty.ravel()], 1), axis=0):
            m = (tx == a) & (ty == b)
            out[m] = self._tile(int(a), int(b))[py[m], px[m]]
        return out

    def sample(self, lat, lon):
        lat = np.atleast_1d(np.asarray(lat, float)); lon = np.atleast_1d(np.asarray(lon, float))
        fx, fy = tile_coords(lat, lon, self.z)
        gx, gy = fx * 256 - 0.5, fy * 256 - 0.5
        x0, y0 = np.floor(gx).astype(np.int64), np.floor(gy).astype(np.int64)
        wx, wy = gx - x0, gy - y0
        v00, v10 = self._pixels(x0, y0), self._pixels(x0 + 1, y0)
        v01, v11 = self._pixels(x0, y0 + 1), self._pixels(x0 + 1, y0 + 1)
        return v00 * (1 - wx) * (1 - wy) + v10 * wx * (1 - wy) + v01 * (1 - wx) * wy + v11 * wx * wy


class FallbackSampler:
    def __init__(self, samplers):
        self.samplers = samplers

    def sample(self, lat, lon):
        lat = np.atleast_1d(np.asarray(lat, float)); lon = np.atleast_1d(np.asarray(lon, float))
        out = self.samplers[0].sample(lat, lon)
        for s in self.samplers[1:]:
            m = np.isnan(out)
            if m.any():
                out[m] = s.sample(lat[m], lon[m])
        return out


def default_sampler(cache=None):
    cache = cache or TileCache()
    return FallbackSampler([DemSampler(cache, "dem5a_png", 15), DemSampler(cache, "dem10b_png", 14)])
```

```python
import math
import re

from dataclasses import asdict, dataclass
from pathlib import Path

import requests

ENDPOINTS = ["https://overpass-api.de/api/interpreter",
             "https://maps.mail.ru/osm/tools/overpass/api/interpreter",
             "https://overpass.kumi.systems/api/interpreter"]
ROUTE70_QUERY = '[out:json][timeout:90];way["ref"="70"]["highway"](35.36,139.15,35.52,139.32);out tags geom;'
PARKING_QUERY = '[out:json][timeout:60];way["amenity"="parking"](around:{r},{lat},{lon});out tags geom;'


def _post(url, query):
    r = requests.post(url, data={"data": query}, timeout=120, headers={"User-Agent": "yabitsu-track-builder"})
    return r.status_code, r.text


def fetch_overpass(query, cache_path, post=None, endpoints=ENDPOINTS, retries_per_endpoint=2, wait=5.0):
    cache_path = Path(cache_path)
    if cache_path.exists():
        return json.loads(cache_path.read_text(encoding="utf-8"))
    post = post or _post
    errors = []
    for url in endpoints:
        for attempt in range(retries_per_endpoint):
            try:
                status, text = post(url, query)
            except requests.RequestException as e:
                errors.append(f"{url}: {e}"); continue
            if status == 200:
                data = json.loads(text)
                cache_path.parent.mkdir(parents=True, exist_ok=True)
                cache_path.write_text(text, encoding="utf-8")
                return data
            errors.append(f"{url}: {status}")
            if status not in (429, 502, 503, 504):
                break
            if wait:
                time.sleep(wait * (attempt + 1))
    raise RuntimeError("Overpass からの取得に失敗しました: " + "; ".join(errors))


def parse_lanes(v) -> int:
    m = re.match(r"\s*(\d+)", str(v)) if v is not None else None
    return int(m.group(1)) if m else 0

        Path(path).write_text(json.dumps(asdict(self)), encoding="utf-8")

    @classmethod
    def from_json(cls, path):
        return cls(**json.loads(Path(path).read_text(encoding="utf-8")))


def _key(p):
    return (round(p["lat"], 7), round(p["lon"], 7))


def _dist(a, b):
    lat = math.radians((a[0] + b[0]) / 2)
    return math.hypot((b[1] - a[1]) * 111320 * math.cos(lat), (b[0] - a[0]) * 110574)


def shortest_route(elements, start, end) -> Route:
    adj = defaultdict(dict)
    for w in elements:
        if w.get("type") != "way" or "geometry" not in w:
            continue
        ks = [_key(p) for p in w["geometry"]]
        for a, b in zip(ks, ks[1:]):
            adj[a][b] = w.get("tags", {}); adj[b][a] = w.get("tags", {})
    a = min(adj, key=lambda k: _dist(k, start)); b = min(adj, key=lambda k: _dist(k, end))
    dist, prev, h = {a: 0.0}, {}, [(0.0, a)]
    while h:
        d, u = heapq.heappop(h)
        if u == b:
            break
        if d > dist[u]:
            continue
        for v in adj[u]:
            nd = d + _dist(u, v)
            if nd < dist.get(v, math.inf):
                dist[v], prev[v] = nd, u
                heapq.heappush(h, (nd, v))
    if b not in dist:
        raise ValueError("始点と終点がつながっていません")
    path = [b]
    while path[-1] != a:
        path.append(prev[path[-1]])
    path.reverse()
    tags = [adj[u][v] for u, v in zip(path, path[1:])]
    return Route([p[0] for p in path], [p[1] for p in path], [parse_lanes(t.get("lanes")) for t in tags],
                 [t.get("bridge", "no") != "no" for t in tags])


def parking_polygons(elements):
    return [{"name": w.get("tags", {}).get("name", ""), "lat": [p["lat"] for p in w["geometry"]],
             "lon": [p["lon"] for p in w["geometry"]]}
            for w in elements if w.get("type") == "way" and w.get("tags", {}).get("amenity") == "parking"]
```

```python
import csv
from dataclasses import dataclass
from pathlib import Path

import numpy as np
from scipy.ndimage import gaussian_filter1d

from . import geo


@dataclass
class Centerline:
    s: np.ndarray
    x: np.ndarray
    y: np.ndarray
    heading: np.ndarray
    curvature: np.ndarray
    lanes: np.ndarray
    bridge: np.ndarray
    step: float

    def save(self, path):
        Path(path).parent.mkdir(parents=True, exist_ok=True)
        np.savez(path, **{k: getattr(self, k) for k in ("s", "x", "y", "heading", "curvature", "lanes", "bridge")},
                 step=self.step)

    @classmethod
    def load(cls, path):
        d = np.load(path)
        return cls(d["s"], d["x"], d["y"], d["heading"], d["curvature"], d["lanes"], d["bridge"], float(d["step"]))


def _cum(xy):
    return np.r_[0.0, np.cumsum(np.hypot(*np.diff(xy, axis=0).T))]


def resample_polyline(xy, step=1.0):
    xy = np.asarray(xy, float)
    keep = np.r_[True, np.hypot(*np.diff(xy, axis=0).T) > 1e-9]
    xy = xy[keep]
    s = _cum(xy)
    n = max(1, int(round(s[-1] / step)))
    s_new = np.linspace(0.0, s[-1], n + 1)
    return s_new, np.c_[np.interp(s_new, s, xy[:, 0]), np.interp(s_new, s, xy[:, 1])], s[-1] / n


def seg_value_at(s_vert, seg_values, s_query):
    j = np.clip(np.searchsorted(s_vert, s_query, side="right") - 1, 0, len(seg_values) - 1)
    return np.asarray(seg_values)[j]


def smooth_xy(xy, sigma_m, step):
    sg = sigma_m / step
    return np.c_[gaussian_filter1d(xy[:, 0], sg, mode="nearest"), gaussian_filter1d(xy[:, 1], sg, mode="nearest")]


def heading_curvature(xy, step):
    dx, dy = np.gradient(xy[:, 0], step), np.gradient(xy[:, 1], step)
    ddx, ddy = np.gradient(dx, step), np.gradient(dy, step)
    return np.unwrap(np.arctan2(dy, dx)), (dx * ddy - dy * ddx) / np.power(dx * dx + dy * dy, 1.5)


def apply_offsets(s, xy, heading, offsets):
    offsets = np.asarray(offsets, float).reshape(-1, 2)
    if len(offsets) == 0:
        return xy.copy()
    o = np.argsort(offsets[:, 0])
    lat = np.interp(s, offsets[o, 0], offsets[o, 1])
    return xy + lat[:, None] * np.c_[-np.sin(heading), np.cos(heading)]


def load_offsets_csv(path):
    p = Path(path)
    if not p.exists():
        return np.zeros((0, 2))
    with p.open(encoding="utf-8") as f:
        rows = [(float(r["s_m"]), float(r["lateral_m"])) for r in csv.DictReader(f) if r.get("s_m")]
    return np.array(rows, float).reshape(-1, 2)


def build_centerline(route, project=geo.to_local, step=1.0, sigma_m=4.0, offsets=None):
    x, y = project(np.asarray(route.lat, float), np.asarray(route.lon, float))
    raw = np.c_[x, y]
    s_vert = _cum(raw)
    s, xy, st = resample_polyline(raw, step)
    lanes = seg_value_at(s_vert, route.seg_lanes, s)
    bridge = seg_value_at(s_vert, route.seg_bridge, s).astype(bool)
    xy = smooth_xy(xy, sigma_m, st)
    if offsets is not None and len(offsets):
        h, _ = heading_curvature(xy, st)
        xy = smooth_xy(apply_offsets(s, xy, h, offsets), 2.0, st)
        s_old = _cum(xy)
        s, xy, st = resample_polyline(xy, step)
        lanes = seg_value_at(s_old, lanes[:-1], s)
        bridge = seg_value_at(s_old, bridge[:-1], s).astype(bool)
    h, k = heading_curvature(xy, st)
    return Centerline(s, xy[:, 0], xy[:, 1], h, k, lanes.astype(np.int32), bridge, st)
```

```python
from pathlib import Path

import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
import numpy as np
from scipy.ndimage import binary_dilation, gaussian_filter1d, median_filter

from . import geo

SIGMAS = (30, 25, 20, 16, 12, 10, 8, 6, 5, 4, 3)


def raw_profile(cl, sampler, unproject=geo.from_local):
    lat, lon = unproject(cl.x, cl.y)
    return sampler.sample(lat, lon)


def valid_mask(z_raw, bridge, step, margin_m=5.0):
    b = np.asarray(bridge, bool)
    if b.any():
        b = binary_dilation(b, iterations=max(1, int(round(margin_m / step))))
    return ~np.isnan(z_raw) & ~b


def _fill(s, z, valid):
    return np.interp(s, s[valid], z[valid])


def despike(z, valid, step, window_m=9.0):
    w = max(3, int(round(window_m / step)) | 1)
    return median_filter(z, size=w, mode="nearest")


def fit_profile(s, z_raw, valid, step, tol=1.5, sigmas=SIGMAS):
    zref = despike(_fill(s, z_raw, valid), valid, step)
    z = zref
    for sg in sigmas:
        z = gaussian_filter1d(zref, sg / step, mode="nearest")
        if np.abs(z - zref)[valid].max() <= tol:
            return z, zref, sg
    return z, zref, sigmas[-1]


def profile_stats(s, z, z_ref, valid, step, tol=1.5):
    k = max(1, int(round(10 / step)))
    grade = (z[k:] - z[:-k]) / (s[k:] - s[:-k]) * 100
    curv = np.gradient(np.gradient(z, step), step)
    r = np.abs(z - z_ref)[valid]
    return {"length_m": float(s[-1] - s[0]), "z_start": float(z[0]), "z_end": float(z[-1]),
            "rise_m": float(z[-1] - z[0]), "max_grade_pct": float(np.abs(grade).max()),
            "mean_grade_pct": float((z[-1] - z[0]) / (s[-1] - s[0]) * 100),
            "max_vertical_curvature": float(np.abs(curv).max()), "max_residual_m": float(r.max()),
            "pct_within_tol": float((r <= tol).mean() * 100)}


def plot_profile(png, s, z_ref, z, valid, title):
    Path(png).parent.mkdir(parents=True, exist_ok=True)
    fig, (a, b) = plt.subplots(2, 1, figsize=(14, 8), sharex=True)
```

```python
import io

import numpy as np
from PIL import Image, ImageDraw

from .gsi import tile_coords


def render_local_image(cache, unproject, x0, y0, size_m, px_size=0.5, layer="seamlessphoto", z=18, ext="jpg"):
    n = int(round(size_m / px_size))
    xs = x0 + (np.arange(n) + 0.5) * px_size
    ys = y0 + size_m - (np.arange(n) + 0.5) * px_size
    X, Y = np.meshgrid(xs, ys)
    lat, lon = unproject(X.ravel(), Y.ravel())
    fx, fy = tile_coords(lat, lon, z)
    tx, ty = np.floor(fx).astype(np.int64), np.floor(fy).astype(np.int64)
    px = np.clip(((fx - tx) * 256).astype(np.int64), 0, 255); py = np.clip(((fy - ty) * 256).astype(np.int64), 0, 255)
    out = np.full((n * n, 3), 128, np.uint8)
    for a, b in np.unique(np.stack([tx, ty], 1), axis=0):
        data = cache.get_bytes(layer, z, int(a), int(b), ext)
        if data is None:
            continue
        t = np.array(Image.open(io.BytesIO(data)).convert("RGB"))
        m = (tx == a) & (ty == b)
        out[m] = t[py[m], px[m]]
    return out.reshape(n, n, 3)


def hillshade(zgrid, cell, azimuth=315.0, altitude=45.0):
    dzdy_rows, dzdx = np.gradient(zgrid, cell)
    dzdy = -dzdy_rows  # 行0が北なので、北向きの傾きは符号が逆
    slope = np.arctan(np.hypot(dzdx, dzdy))
    aspect = np.arctan2(-dzdx, -dzdy)  # 斜面が下がっていく方位（北=0、時計回り）
    az, alt = np.radians(azimuth), np.radians(altitude)
    hs = np.sin(alt) * np.cos(slope) + np.cos(alt) * np.sin(slope) * np.cos(az - aspect)
    return np.clip(hs, 0, 1)


def review_chunks(cl, every_m=150.0, size_m=250.0):
    out = []
    for sc in np.arange(0.0, cl.s[-1] + 1e-9, every_m):
        i = int(np.argmin(np.abs(cl.s - sc)))
        out.append((float(sc), float(cl.x[i] - size_m / 2), float(cl.y[i] - size_m / 2)))
    return out


def draw_overlay(img, cl, x0, y0, size_m, px_size, half_width=None):
    im = Image.fromarray(img).convert("RGB")
    d = ImageDraw.Draw(im)
    to_px = lambda x, y: list(zip((np.asarray(x) - x0) / px_size, (y0 + size_m - np.asarray(y)) / px_size))
    d.line(to_px(cl.x, cl.y), fill=(255, 0, 0), width=1)
    if half_width is not None:
        nx, ny = -np.sin(cl.heading), np.cos(cl.heading)
        for sgn in (1, -1):
            d.line(to_px(cl.x + sgn * half_width * nx, cl.y + sgn * half_width * ny), fill=(255, 255, 0), width=1)
    for sv in range(0, int(cl.s[-1]) + 1, 50):
        i = int(np.argmin(np.abs(cl.s - sv)))
        (px, py), = to_px([cl.x[i]], [cl.y[i]])
        if 0 <= px < im.width and 0 <= py < im.height:
            d.ellipse([px - 2, py - 2, px + 2, py + 2], outline=(0, 255, 255)); d.text((px + 4, py - 6), str(sv), fill=(0, 255, 255))
    return im
```

`yabitsu/crosssection.py`：

```python
import csv
import json
from dataclasses import dataclass, fields
from pathlib import Path

import numpy as np
from scipy.ndimage import gaussian_filter1d
from shapely.geometry import Point, Polygon

from . import geo

DEFAULT_WIDTH_BY_LANES = {0: 4.0, 1: 4.0, 2: 6.0}
GUTTER_WIDTH = 0.6
GUTTER_DEPTH = 0.12
SKIRT_DEPTH = 0.5
CROWN_SLOPE = 0.02


def surface_height(lat, z_c, slope, crown):
    return z_c + slope * lat - crown * np.abs(lat)


def load_widths_csv(path):
    p = Path(path)
    if not p.exists():
        return []
    with p.open(encoding="utf-8") as f:
        return [{"s_from": float(r["s_from"]), "s_to": float(r["s_to"]), "width_m": float(r["width_m"]),
                 "lanes": int(r["lanes"]) if r.get("lanes") else None} for r in csv.DictReader(f) if r.get("s_from")]


def widths(s, lanes, rows):
    lanes = np.asarray(lanes).astype(np.int32).copy()
    w = np.array([DEFAULT_WIDTH_BY_LANES.get(int(l), 6.0) for l in lanes])
    for r in rows:
        m = (s >= r["s_from"]) & (s <= r["s_to"])
        w[m] = r["width_m"]
        if r.get("lanes"):
            lanes[m] = r["lanes"]
    return w, lanes


def cross_slope(curvature, lanes, step, max_slope=0.06, k_full=1 / 40, min_slope=0.02, smooth_m=15.0):
    k = np.asarray(curvature, float); lanes = np.asarray(lanes)
    se = -np.sign(k) * np.minimum(max_slope, max_slope * np.abs(k) / k_full)
    se = gaussian_filter1d(se, smooth_m / step, mode="nearest")
    two = lanes >= 2
    crown = np.where(two, CROWN_SLOPE * np.clip(1 - np.abs(se) / (2 * min_slope), 0, 1), 0.0)
    small = ~two & (np.abs(se) < min_slope)
    se = np.where(small, np.where(se > 0, 1.0, -1.0) * min_slope, se)
    se = np.where(two, se, gaussian_filter1d(se, 5.0 / step, mode="nearest"))
    return se, gaussian_filter1d(crown, 5.0 / step, mode="nearest")


@dataclass
class Section:
    s: np.ndarray
    x: np.ndarray
    y: np.ndarray
    z: np.ndarray
    heading: np.ndarray
    curvature: np.ndarray
    lanes: np.ndarray
    bridge: np.ndarray
    hw_left: np.ndarray
    hw_right: np.ndarray
    slope: np.ndarray
    crown: np.ndarray

    @property
    def n(self):
        return len(self.s)

    def edge_z(self, side):
        hw = self.hw_left if side > 0 else self.hw_right
        return surface_height(side * hw, self.z, self.slope, self.crown)

    def path(self):
        return {"s": self.s, "x": self.x, "y": self.y, "z": self.z, "heading": self.heading}

    def save_json(self, path):
        Path(path).parent.mkdir(parents=True, exist_ok=True)
        Path(path).write_text(json.dumps({f.name: np.asarray(getattr(self, f.name)).tolist() for f in fields(self)}),
                              encoding="utf-8")

    @classmethod
    def load_json(cls, path):
        d = json.loads(Path(path).read_text(encoding="utf-8"))
        kinds = {"lanes": np.int32, "bridge": bool}
        return cls(**{k: np.asarray(v, kinds.get(k, np.float64)) for k, v in d.items()})


def build_section(cl, z, width_rows):
    w, lanes = widths(cl.s, cl.lanes, width_rows)
    slope, crown = cross_slope(cl.curvature, lanes, cl.step)
    return Section(cl.s, cl.x, cl.y, np.asarray(z, float), cl.heading, cl.curvature, lanes, cl.bridge,
                   w / 2, w / 2, slope, crown)


def pads_from_parking(parking, sec, project=geo.to_local, max_dist=150.0):
    ends = {"start": np.array([sec.x[0], sec.y[0]]), "end": np.array([sec.x[-1], sec.y[-1]])}
    out = []
    for p in parking:
        x, y = project(np.asarray(p["lat"], float), np.asarray(p["lon"], float))
        poly = Polygon(np.c_[x, y]).buffer(0)
        c = np.array(poly.centroid.coords[0])
        role, d = min(((r, np.linalg.norm(c - e)) for r, e in ends.items()), key=lambda t: t[1])
        if d > max_dist:
            continue
        i = int(np.argmin(np.hypot(sec.x - c[0], sec.y - c[1])))
        out.append({"name": p["name"], "role": role, "polygon": np.asarray(poly.exterior.coords).tolist(), "z": float(sec.z[i])})
    return out
```

```python
from pathlib import Path

import numpy as np
from PIL import Image

MATERIALS = {
    "asphalt": {"texture": "textures/asphalt.png", "shader": "ksPerPixel"},
    "concrete": {"texture": "textures/concrete.png", "shader": "ksPerPixel"},
    "ground": {"texture": "textures/ground.png", "shader": "ksPerPixel"},
    "line_white": {"texture": "textures/line_white.png", "shader": "ksPerPixel"},
    "guardrail": {"texture": "textures/guardrail.png", "shader": "ksPerPixel", "two_sided": True},
    "tree": {"texture": "textures/tree.png", "shader": "ksPerPixelAT", "alpha": True, "two_sided": True},
}


def periodic_noise(size, feature_px, rng):
    f = np.fft.fftfreq(size)
    fx, fy = np.meshgrid(f, f)
    filt = np.exp(-(fx ** 2 + fy ** 2) * (feature_px ** 2) * 2.0)
    n = np.real(np.fft.ifft2(np.fft.fft2(rng.standard_normal((size, size))) * filt))
    return (n - n.min()) / (n.max() - n.min())


def _u8(a):
    return np.clip(np.asarray(a) * 255, 0, 255).astype(np.uint8)


def _gray(size, seed, base, amp, tint=(1.0, 1.0, 1.0), coarse=48, fine=3, specks=0.0):
    rng = np.random.default_rng(seed)
    n = 0.6 * periodic_noise(size, coarse, rng) + 0.4 * periodic_noise(size, fine, rng)
    g = base + amp * (n - 0.5)
    if specks:
        g = np.where(rng.random((size, size)) < specks, g + 0.12, g)
    return _u8(np.stack([g * tint[0], g * tint[1], g * tint[2]], -1))


def ground(size=1024, seed=4):
    rng = np.random.default_rng(seed)
    t = periodic_noise(size, 96, rng)[..., None]; d = periodic_noise(size, 4, rng)[..., None]
    green, brown = np.array([0.20, 0.28, 0.11]), np.array([0.30, 0.25, 0.16])
    return _u8((green * (1 - t) + brown * t) * (0.85 + 0.3 * d))


def tree_card(w=512, h=1024, seed=5):
    rng = np.random.default_rng(seed)
    yy, xx = np.mgrid[0:h, 0:w].astype(float)
    edge = periodic_noise(max(w, h), 6, rng)[:h, :w]
    crown_h = 0.85 * h
    half = np.where(yy < crown_h, (yy / crown_h) * 0.46 * w * (0.8 + 0.4 * edge), 0.0)
    trunk = (yy >= crown_h * 0.95) & (np.abs(xx - w / 2) < 0.035 * w)
    mask = (np.abs(xx - w / 2) < half) | trunk
    shade = 0.6 + 0.4 * periodic_noise(max(w, h), 10, rng)[:h, :w]
    rgb = np.where(trunk[..., None], np.array([0.25, 0.18, 0.12]), np.array([0.10, 0.22, 0.09]) * shade[..., None] * 1.6)
    return np.dstack([_u8(rgb), np.where(mask, 255, 0).astype(np.uint8)])


def write_textures(out_dir):
    out = Path(out_dir); out.mkdir(parents=True, exist_ok=True)
    imgs = {"asphalt": _gray(1024, 1, 0.26, 0.10, (1.0, 1.0, 1.02), specks=0.005),
            "concrete": _gray(1024, 2, 0.58, 0.12, (1.02, 1.0, 0.96)),
            "ground": ground(),
            "line_white": _gray(256, 3, 0.86, 0.06),
            "guardrail": _gray(256, 6, 0.74, 0.08, coarse=24),
            "tree": tree_card()}
    paths = {}
    for name, a in imgs.items():
        paths[name] = out / Path(MATERIALS[name]["texture"]).name
        Image.fromarray(a).save(paths[name])
    return paths


def register_materials(m):
    for name, spec in MATERIALS.items():
        m.add_material(name, texture=spec["texture"], alpha=spec.get("alpha", False), two_sided=spec.get("two_sided", False))
```

```python
import numpy as np

from .crosssection import GUTTER_DEPTH, GUTTER_WIDTH, SKIRT_DEPTH, surface_height


def ribbon(x, y, heading, lat, z, s, u_scale=4.0, v_scale=4.0, face_mask=None, flip=False):
    lat = np.asarray(lat, float); z = np.asarray(z, float)
    N, M = lat.shape
    nx, ny = -np.sin(heading)[:, None], np.cos(heading)[:, None]
    X = np.asarray(x)[:, None] + lat * nx; Y = np.asarray(y)[:, None] + lat * ny
    verts = np.stack([X, Y, z], -1).reshape(-1, 3)
    d = np.sqrt(np.diff(X, axis=1) ** 2 + np.diff(Y, axis=1) ** 2 + np.diff(z, axis=1) ** 2)
    u = np.c_[np.zeros(N), np.cumsum(d, axis=1)] / u_scale
    v = np.broadcast_to(np.asarray(s)[:, None] / v_scale, (N, M))
    uvs = np.stack([u, v], -1).reshape(-1, 2)
    i = np.arange(N * M).reshape(N, M)
    faces = np.stack([i[:-1, :-1], i[1:, :-1], i[1:, 1:], i[:-1, 1:]], -1).reshape(-1, 4)
    if face_mask is not None:
        faces = faces[np.asarray(face_mask, bool).reshape(-1)]
    if flip:
        faces = faces[:, ::-1]
    return verts, faces, uvs


def face_normals(verts, faces):
    p = verts[faces]
    q = np.roll(p, -1, axis=1)
    n = np.stack([((p[..., 1] - q[..., 1]) * (p[..., 2] + q[..., 2])).sum(1),
                  ((p[..., 2] - q[..., 2]) * (p[..., 0] + q[..., 0])).sum(1),
                  ((p[..., 0] - q[..., 0]) * (p[..., 1] + q[..., 1])).sum(1)], -1)
    return n / np.maximum(np.linalg.norm(n, axis=1, keepdims=True), 1e-12)


def folded_faces(verts, faces):
    return np.nonzero(face_normals(verts, faces)[:, 2] <= 0)[0]


def compact(verts, faces, uvs):
    used, inv = np.unique(faces.ravel(), return_inverse=True)
    return verts[used], inv.reshape(faces.shape), uvs[used]


def split_rows(n, rows_per_chunk):
    out, i = [], 0
    while i < n - 1:
        j = min(i + rows_per_chunk, n - 1); out.append((i, j)); i = j
    return out


def _cols(sec, sl, a):
    return np.asarray(a)[sl][:, None]


def road_surface(sec, sl, n_lat=5):
    fr = np.linspace(-1, 1, n_lat)[None, :]
    lat = np.where(fr < 0, fr * _cols(sec, sl, sec.hw_right), fr * _cols(sec, sl, sec.hw_left))
    z = surface_height(lat, _cols(sec, sl, sec.z), _cols(sec, sl, sec.slope), _cols(sec, sl, sec.crown))
    return ribbon(sec.x[sl], sec.y[sl], sec.heading[sl], lat, z, sec.s[sl])


def gutter(sec, sl, side):
    hw = _cols(sec, sl, sec.hw_left if side > 0 else sec.hw_right)
    z_edge = surface_height(side * hw, _cols(sec, sl, sec.z), _cols(sec, sl, sec.slope), _cols(sec, sl, sec.crown))
    offs = np.array([0.0, GUTTER_WIDTH / 2, GUTTER_WIDTH, GUTTER_WIDTH])[None, :]
    dz = np.array([0.0, -GUTTER_DEPTH, 0.0, -SKIRT_DEPTH])[None, :]
    lat = side * (hw + offs); z = z_edge + dz
    if side < 0:
        lat, z = lat[:, ::-1], z[:, ::-1]
    return ribbon(sec.x[sl], sec.y[sl], sec.heading[sl], lat, z, sec.s[sl], u_scale=1.0)


def line(sec, sl, center_lat, width=0.15, lift=0.005, dash=None, row_mask=None):
    lat = np.asarray(center_lat, float)[:, None] + np.array([-width / 2, width / 2])[None, :]
    z = surface_height(lat, _cols(sec, sl, sec.z), _cols(sec, sl, sec.slope), _cols(sec, sl, sec.crown)) + lift
    s = sec.s[sl]
    mask = np.ones(len(s) - 1, bool)
    if dash is not None:
        on, off = dash
        mask &= (s[:-1] % (on + off)) < on
    if row_mask is not None:
        mask &= np.asarray(row_mask, bool)
    return ribbon(sec.x[sl], sec.y[sl], sec.heading[sl], lat, z, s, u_scale=1.0, face_mask=mask[:, None])


def wall_ribbon(sec, sl, side, lat_bottom, lat_top, z_bottom, z_top):
    lat = np.stack([side * np.asarray(lat_bottom, float), side * np.asarray(lat_top, float)], 1)
    z = np.stack([np.asarray(z_bottom, float), np.asarray(z_top, float)], 1)
    return ribbon(sec.x[sl], sec.y[sl], sec.heading[sl], lat, z, sec.s[sl], u_scale=2.0, flip=side < 0)
```

（`ribbon` の面の順番は a=(i,j) → (i+1,j) → (i+1,j+1) → (i,j+1)。進行方向を東、lat が増える方向を北とすると、上から見て反時計回りで上向きになる。）

```python
import numpy as np
import shapely
from scipy.spatial import cKDTree
from shapely.geometry import Polygon

from . import geo
from .crosssection import GUTTER_WIDTH, surface_height
from .meshgen import compact

FILL_SLOPE, CUT_SLOPE, UNDER_DEPTH = 1.0, 2.0, 0.3
NEAR_BAND, NEAR_CELL = 110.0, 2.0
FAR_EXTENT, FAR_CELL, FAR_HOLE, FAR_DROP = 2000.0, 20.0, 95.0, 1.0


def corridor_grid(sec, band=NEAR_BAND, cell=NEAR_CELL):
    xs = np.arange(np.floor((sec.x.min() - band) / cell) * cell, sec.x.max() + band + cell, cell)
    ys = np.arange(np.floor((sec.y.min() - band) / cell) * cell, sec.y.max() + band + cell, cell)
    return xs, ys


def road_frame(sec, X, Y):
    P = np.c_[np.ravel(X), np.ravel(Y)]
    dist, idx = cKDTree(np.c_[sec.x, sec.y]).query(P)
    h = sec.heading[idx]
    dx, dy = P[:, 0] - sec.x[idx], P[:, 1] - sec.y[idx]
    return {"idx": idx, "lat": -dx * np.sin(h) + dy * np.cos(h), "along": dx * np.cos(h) + dy * np.sin(h), "dist": dist}


def carve(X, Y, Z_nat, sec, pads=(), cut_left=None, cut_right=None):
    shape = np.shape(X)
    f = road_frame(sec, X, Y)
    idx, lat, along = f["idx"], f["lat"], f["along"]
    left = lat >= 0
    hw = np.where(left, sec.hw_left[idx], sec.hw_right[idx])
    form = hw + GUTTER_WIDTH
    zc, sl, cr = sec.z[idx], sec.slope[idx], sec.crown[idx]
    z_edge = surface_height(np.where(left, hw, -hw), zc, sl, cr)
    e = np.hypot(np.maximum(np.abs(lat) - form, 0), np.maximum(np.abs(along) - 0.75, 0))
    cl_ = np.full(sec.n, CUT_SLOPE) if cut_left is None else np.asarray(cut_left)
    cr_ = np.full(sec.n, CUT_SLOPE) if cut_right is None else np.asarray(cut_right)
    cut = np.where(left, cl_[idx], cr_[idx])
    z = np.clip(np.ravel(Z_nat), z_edge - FILL_SLOPE * e, z_edge + cut * e)
    z = np.where(e == 0, surface_height(np.clip(lat, -hw, hw), zc, sl, cr) - UNDER_DEPTH, z)
    if pads:
        pts = shapely.points(np.c_[np.ravel(X), np.ravel(Y)])
        for p in pads:
            d = shapely.distance(pts, Polygon(p["polygon"]))
            z = np.where(d == 0, p["z"] - UNDER_DEPTH, np.clip(z, p["z"] - FILL_SLOPE * d, p["z"] + CUT_SLOPE * d))
            e = np.where(d == 0, 0.0, np.minimum(e, d))
    return z.reshape(shape), e.reshape(shape)


def grid_mesh_chunks(xs, ys, Z, face_keep, block=100, uv_scale=8.0):
    X, Y = np.meshgrid(xs, ys)
    verts = np.c_[X.ravel(), Y.ravel(), Z.ravel()]
    uvs = verts[:, :2] / uv_scale
    i = np.arange(X.size).reshape(X.shape)
    faces = np.stack([i[:-1, :-1], i[:-1, 1:], i[1:, 1:], i[1:, :-1]], -1)
    ry, rx = np.meshgrid(np.arange(Z.shape[0] - 1) // block, np.arange(Z.shape[1] - 1) // block, indexing="ij")
    keep = np.asarray(face_keep, bool)
    out = []
    for by, bx in sorted(set(zip(ry[keep].tolist(), rx[keep].tolist()))):
        m = keep & (ry == by) & (rx == bx)
        out.append(compact(verts, faces[m].reshape(-1, 4), uvs))
    return out


def _sample(sampler, unproject, X, Y):
    lat, lon = unproject(X.ravel(), Y.ravel())
    z = sampler.sample(lat, lon)
    if np.isnan(z).any():
        z[np.isnan(z)] = np.nanmedian(z)
    return z.reshape(X.shape)


def build_near(sec, sampler, pads, cut_left=None, cut_right=None, unproject=geo.from_local):
    xs, ys = corridor_grid(sec)
    X, Y = np.meshgrid(xs, ys)
    D = road_frame(sec, X, Y)["dist"].reshape(X.shape)
    Z, E = carve(X, Y, _sample(sampler, unproject, X, Y), sec, pads, cut_left, cut_right)
    return {"xs": xs, "ys": ys, "Z": Z, "E": E, "D": D}


def build_far(sec, sampler, unproject=geo.from_local):
    xs, ys = corridor_grid(sec, FAR_EXTENT + NEAR_BAND, FAR_CELL)
    X, Y = np.meshgrid(xs, ys)
    Z = _sample(sampler, unproject, X, Y) - FAR_DROP
    cx, cy = np.meshgrid((xs[:-1] + xs[1:]) / 2, (ys[:-1] + ys[1:]) / 2)
    Dc = road_frame(sec, cx, cy)["dist"].reshape(cx.shape)
    return {"xs": xs, "ys": ys, "Z": Z, "Dc": Dc}
```

```python
from dataclasses import dataclass
from pathlib import Path

import numpy as np

from . import geo
from .crosssection import GUTTER_WIDTH
from .meshgen import wall_ribbon
from .terrain import CUT_SLOPE

WALL_LEAN = 0.3
WALL_CUT_SLOPE = 3.0
GUARDRAIL_OFFSET = 0.1
SIDES = {"L": 1, "R": -1}
TYPES = ("guardrail", "retaining_wall")


@dataclass
class Feature:
    s_from: float
    s_to: float
    side: str
    type: str
    height_m: float
    note: str


def load_features_csv(path):
    p = Path(path)
    if not p.exists():
        return []
    with p.open(encoding="utf-8") as f:
        return [Feature(float(r["s_from"]), float(r["s_to"]), r["side"].strip(), r["type"].strip(),
                        float(r["height_m"]) if r.get("height_m") else 0.0, r.get("note") or "")
                for r in csv.DictReader(f) if r.get("s_from")]


def rows_of(sec, f):
    if f.side not in SIDES or f.type not in TYPES:
        raise ValueError(f"side は L/R、type は {TYPES} のどれか: {f}")
    if not (0 <= f.s_from < f.s_to <= sec.s[-1] + 1e-6):
        raise ValueError(f"範囲が区間の外か逆順です（0〜{sec.s[-1]:.0f}m）: {f}")
    i0 = int(np.searchsorted(sec.s, f.s_from)); i1 = int(np.searchsorted(sec.s, f.s_to, side="right")) - 1
    return slice(i0, i1 + 1)


def cut_slopes(sec, feats):
    cut = {1: np.full(sec.n, CUT_SLOPE), -1: np.full(sec.n, CUT_SLOPE)}
    for f in feats:
        if f.type == "retaining_wall":
            cut[SIDES[f.side]][rows_of(sec, f)] = WALL_CUT_SLOPE
    return cut[1], cut[-1]


def _side_arrays(sec, f):
    sl = rows_of(sec, f); side = SIDES[f.side]
    hw = (sec.hw_left if side > 0 else sec.hw_right)[sl]
    return sl, side, hw, sec.edge_z(side)[sl]


def guardrail_meshes(sec, f):
    sl, side, hw, ze = _side_arrays(sec, f)
    L = hw + GUTTER_WIDTH + GUARDRAIL_OFFSET
    visual = wall_ribbon(sec, sl, side, L, L, ze + 0.55, ze + 0.85)
    collision = wall_ribbon(sec, sl, side, L, L, ze - 0.3, ze + 1.2)
    return visual, collision


def retaining_wall_mesh(sec, f):
    sl, side, hw, ze = _side_arrays(sec, f)
    L0 = hw + GUTTER_WIDTH
    return wall_ribbon(sec, sl, side, L0, L0 + WALL_LEAN * f.height_m, ze - 0.3, ze + f.height_m)


def _runs(mask, s, min_len, max_gap):
    out, start, last = [], None, None
    for i, m in enumerate(mask):
        if m:
            if start is None or s[i] - s[last] > max_gap:
                if start is not None and s[last] - s[start] >= min_len:
                    out.append((start, last))
                start = i
            last = i
    if start is not None and s[last] - s[start] >= min_len:
        out.append((start, last))
    return out


def suggest_candidates(sec, z_natural, threshold=2.5, min_len=10.0, max_gap=5.0):
    out = []
    for tag, side in SIDES.items():
        hw = sec.hw_left if side > 0 else sec.hw_right
        L = side * (hw + GUTTER_WIDTH + 4.0)
        x = sec.x - L * np.sin(sec.heading); y = sec.y + L * np.cos(sec.heading)
        diff = np.asarray(z_natural(x, y)) - sec.edge_z(side)
        for kind, mask in (("retaining_wall", diff > threshold), ("guardrail", diff < -threshold)):
            for a, b in _runs(mask, sec.s, min_len, max_gap):
                mid = (a + b) // 2
                lat, lon = geo.from_local(sec.x[mid], sec.y[mid])
                h = float(np.clip(np.median(diff[a:b + 1]) - 1.0, 1.0, 6.0)) if kind == "retaining_wall" else 0.0
                out.append({"s_from": round(float(sec.s[a])), "s_to": round(float(sec.s[b])), "side": tag, "type": kind,
                            "height_m": round(h, 1),
                            "streetview": f"https://www.google.com/maps/@?api=1&map_action=pano&viewpoint={float(lat):.6f},{float(lon):.6f}"})
    return sorted(out, key=lambda r: r["s_from"])
```

```python
import numpy as np
import shapely
from scipy.interpolate import RegularGridInterpolator
from shapely.geometry import Polygon

from .crosssection import GUTTER_WIDTH


def scatter(near, pads=(), density=1 / 40, clear_m=3.0, band=105.0, seed=7):
    rng = np.random.default_rng(seed)
    xs, ys = near["xs"], near["ys"]
    n = int((xs[-1] - xs[0]) * (ys[-1] - ys[0]) * density)
    P = np.c_[rng.uniform(xs[0], xs[-1], n), rng.uniform(ys[0], ys[-1], n)]
    q = P[:, ::-1]
    E = RegularGridInterpolator((ys, xs), near["E"])(q); D = RegularGridInterpolator((ys, xs), near["D"])(q)
    keep = (E >= clear_m) & (D <= band)
    if pads:
        pts = shapely.points(P)
        for p in pads:
            keep &= shapely.distance(pts, Polygon(p["polygon"])) > clear_m
    P = P[keep]
    z = RegularGridInterpolator((ys, xs), near["Z"])(P[:, ::-1])
    return np.c_[P, z, rng.uniform(8.0, 16.0, len(P))]


def cards(trees, seed=8):
    rng = np.random.default_rng(seed)
    verts, uvs, faces = [], [], []
    for i, (x, y, z, h) in enumerate(trees):
        a = rng.uniform(0, np.pi); w = h * 0.45 / 2
        for j, ang in enumerate((a, a + np.pi / 2)):
            dx, dy = w * np.cos(ang), w * np.sin(ang)
            base = len(verts)
            verts += [(x - dx, y - dy, z), (x + dx, y + dy, z), (x + dx, y + dy, z + h), (x - dx, y - dy, z + h)]
            uvs += [(0, 0), (1, 0), (1, 1), (0, 1)]
            faces.append((base, base + 1, base + 2, base + 3))
    return np.array(verts, float).reshape(-1, 3), np.array(faces, np.int32).reshape(-1, 4), np.array(uvs, float).reshape(-1, 2)


def chunk_ids(trees, size=200.0):
    return (np.floor(trees[:, 0] / size).astype(np.int64) * 100000 + np.floor(trees[:, 1] / size).astype(np.int64))
```

```python
import shapely
from shapely.geometry import Polygon


def pad_mesh(polygon, z):
    tris = shapely.constrained_delaunay_triangles(Polygon(polygon))
    verts, faces = [], []
    for t in tris.geoms:
        c = np.asarray(t.exterior.coords)[:3]
        if (c[1, 0] - c[0, 0]) * (c[2, 1] - c[0, 1]) - (c[1, 1] - c[0, 1]) * (c[2, 0] - c[0, 0]) < 0:
            c = c[::-1]
        b = len(verts); verts += [(p[0], p[1], z) for p in c]; faces.append((b, b + 1, b + 2))
    v = np.array(verts, float)
    return v, np.array(faces, np.int32), v[:, :2] / 4.0
```

```python
import math

import numpy as np
from shapely.geometry import Point, Polygon

from . import acdata
from .acobjects import frame_at, hotlap_start, pit_boxes, start_grid, timing_gate

LAYOUTS = {"s1_up": 1, "s1_down": -1}


def _s_from_start(sec, direction, d):
    return d if direction > 0 else sec.s[-1] - d


def _pits(sec, pads, direction):
    role = "start" if direction > 0 else "end"
    for p in pads:
        if p["role"] != role:
            continue
        poly = Polygon(p["polygon"]); c = poly.centroid
        i = int(np.argmin(np.hypot(sec.x - c.x, sec.y - c.y)))
        h = sec.heading[i] if direction > 0 else sec.heading[i] + math.pi
        boxes = pit_boxes((c.x, c.y), p["z"], math.atan2(math.sin(h), math.cos(h)))
        if all(poly.contains(Point(b.location[0], b.location[1])) for b in boxes):
            return boxes
    # 駐車場が無い・入らないときは、スタート列と同じ場所をピットにする
    # （ピットは練習走行、スタート列はレースで使うので、同時には使われない）
    out = start_grid(sec.path(), _s_from_start(sec, direction, 40.0), direction)
    for i, d in enumerate(out):
        d.name = f"AC_PIT_{i}"
    return out


def layout_objects(sec, pads, direction):
    path = sec.path()
    hw = float(max(sec.hw_left.max(), sec.hw_right.max()))
    return [*start_grid(path, _s_from_start(sec, direction, 40.0), direction),
            hotlap_start(path, _s_from_start(sec, direction, 5.0), direction),
            *timing_gate(path, _s_from_start(sec, direction, 50.0), direction, hw + 1.0, "START"),
            *timing_gate(path, _s_from_start(sec, direction, sec.s[-1] - 30.0), direction, hw + 1.0, "FINISH"),
            *_pits(sec, pads, direction)]


def cameras(sec, direction, every=150.0):
    L = float(sec.s[-1]); path = sec.path(); cams = []
    marks = np.arange(0.0, L, every)
    for k, d in enumerate(marks):
        s = _s_from_start(sec, direction, d)
        x, y, z, h = frame_at(path, s)
        side = 1 if k % 2 == 0 else -1
        off = float((sec.hw_left if side > 0 else sec.hw_right)[int(np.argmin(np.abs(sec.s - s)))]) + 4.0
        cx, cy, cz = x - side * off * math.sin(h), y + side * off * math.cos(h), z + 3.0
        tx, ty, tz, _ = frame_at(path, float(np.clip(s + direction * 20.0, 0, L)))
        pos = acdata.blender_to_ac(cx, cy, cz)
        fwd = acdata.blender_to_ac(tx - cx, ty - cy, tz - cz)
        cams.append(acdata.Camera(f"cam{k:02d}", pos, fwd, max(0.0, (d - every / 2) / L) if k else 0.0,
                                  1.0 if k == len(marks) - 1 else min(1.0, (d + every / 2) / L)))
    return cams
```

```python
import csv
import json
import sys
from pathlib import Path

import numpy as np

from yabitsu import config, elevation
from yabitsu.meshgen import folded_faces


def check(processed_dir, manual_dir):
    P, M = Path(processed_dir), Path(manual_dir)
    pr = np.load(P / "s1_profile.npz")
    st = elevation.profile_stats(pr["s"], pr["z"], pr["z_ref"], pr["valid"], float(pr["s"][1] - pr["s"][0]))
    with (M / "s1_position_review.csv").open(encoding="utf-8") as f:
        rows = list(csv.DictReader(f))
    position_ok = bool(rows) and all(r["ok"].strip().lower() == "yes" and float(r["max_offset_m"]) <= 2.0 for r in rows)
    man = json.loads((P / "s1" / "manifest.json").read_text(encoding="utf-8"))
    folds = tris = 0
    for name in man["groups"]["yabitsu_s1"]["meshes"]:
        d = np.load(P / "s1" / man["meshes"][name]["file"])
        tris += len(d["faces"]) * (d["faces"].shape[1] - 2)
        if name.startswith("1ROAD_s1_") and "gutter" not in name:
            folds += len(folded_faces(d["verts"], d["faces"]))
    return {"elevation_ok": st["max_residual_m"] <= 1.5, "max_residual_m": st["max_residual_m"],
            "max_grade_pct": st["max_grade_pct"], "position_ok": position_ok, "position_rows": len(rows),
            "folds": folds, "tris": tris}


if __name__ == "__main__":
    r = check(config.DATA_PROCESSED, config.DATA_MANUAL)
    print(json.dumps(r, indent=1))
    kn5 = sorted(config.TRACK_DIR.glob("*.kn5"))
    print("kn5:", {p.name: f"{p.stat().st_size / 1e6:.0f} MB" for p in kn5})
    sys.exit(0 if r["elevation_ok"] and r["position_ok"] and r["folds"] == 0 else 1)
```
